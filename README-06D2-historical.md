## التشغيل وإعادة التحقق

Node24+ وpnpm11.25.0. لم تتغير المكتبات أو ملف القفل، ولا يتضمن ZIP مجلدnode_modules. لم تضف المرحلة ترحيل قاعدة بيانات.

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm build
pnpm verify:build
pnpm dev
```

افتح عنوانlocalhost ثم `/#S05` لليوم أو `/#S14` لتقدمي. لا تفتح index.html عبرfile. المستخدم الجديد لا يحصل على نشاط تجريبي. التاريخ الصناعي وأدوات التفويض محصورة في الاختبارات ولا تدخل حزمة المتصفح.

```sh
PW_CHANNEL=chrome python3 scripts/verify-06d2.py --node /path/to/node --browser
```

يلزم Chrome أو Chromium مع Playwright وصلاحيةlocalhost. يسجل الأمر كل نتائج الاختبارات. exit1 لمقارنةFSRS يعني أن التنفيذ المنتخب غير مطابق؛ exit2 لبوابات05-C يعني الحجب. لا يغيّر أمر التحقق أي اعتماد. بعض اختبارات الأداء الموروثة تكتب قياسًا تحت05b؛ احفظ القياس الجديد تحت06d2 واسترجع التقرير التاريخي قبل حزم تسليم جديد.
