# مرشح المصحف النصي V2.1.1

المصدر المختار هو Tanzil Uthmani 1.1. هذه الحزمة تجهز النص الموجود للمراجعة ولا تمنح اعتماد عرضه. لا تنشئ نصًا جديدًا ولا تعدل ملفات `content/06l2` أو أدلتها التاريخية.

أعد التحقق من المستودع بعد تثبيت اعتمادياته:

```sh
node scripts/content-v211-audit.mjs --check
node --test scripts/tests/content-v211-audit.test.mjs
```

ينجح الفحص التقني فقط عند تطابق البايتات مع بصمة المصدر المثبتة والإيصال، وصحة 6236 سجلًا و114 سورة وجميع إزاحات UTF-16. يحسب فهارس مرجعية متصلة إلى sentinel رقم 6236: 604 أوجه مرجعية و30 جزءًا و240 ربع حزب. هذه ليست 240 حزبًا، ولا يثبت الفهرس تطابق العرض مع صفحات مصحف المدينة.

`half-page-map.json` ينفذ نصف الوجه التقريبي بالآيات: أقرب حد آية إلى نصف العدد، والأسبق عند التعادل. للصفحة ذات الآية الواحدة لا ينشئ نصفين؛ لذلك 603 صفحات فقط تقبل هذا التقسيم. التقسيم لا يعتمد على الخط أو عدد أسطر الشاشة.

`candidate-manifest.json` يربط البايتات والفهارس والحقوق ببصماتها الفعلية، ويثبت `displayAllowed=false` و`productionReady=false`. `riwaya` و`fontHash` و`reviewId` و`ownerApprovalId` فارغة عمدًا لأن أدلتها لم تعتمد. أي اختلاف في مدخلات الفهرسة ينتج هوية مرشح مختلفة؛ أي اختلاف في المصدر الخام يوقف الأداة قبل كتابة مخرجات. لا تعدل البصمة المثبتة لإخفاء اختلاف.

الملفات في هذا الدليل مواد مراجعة محجورة خارج `public` وحزم التطبيق. واجهة المعاينة تستورد معلومات غير قرآنية فقط من `src/content/v211-status.ts`. لا تضع النص أو أداة المراجعة أو فهارس الاستخراج في حزمة عامة أو service worker. لا توجد علامة URL أو localStorage لتفعيل النص.

## المتبقي لاعتماد الحزمة ذاتها

- استكمال دليل الرواية وترقيم الآيات والبسملة وعلامات الوقف والسجود، ومراجعة علمية موثقة للحزمة وبصماتها.
- حسم نسخة رخصة XML الدقيقة؛ رأس الملف يقول `cc-by` فقط. تحقق صفحة حقوق النص لا يمنح حقوق الفهرس أو الخط تلقائيًا.
- مقارنة مستقلة متوافقة موثقة أو حسمها لدى المختصين؛ metadata من Tanzil ليست شاهدًا نصيًا مستقلًا.
- اختيار ملف خط محدد برخصة وبصمة، ثم فحص العلامات والتراكب والتكبير والآيات الطويلة وأول/آخر السور على الأجهزة. وجود رخصة Noto دون ملف خط لا يكفي.
- إقرار المراجع المختص ثم موافقة المالكة على `bundleId` والبصمات نفسها؛ تمرير الاختبارات لا يحل محلهما.

نتائج حقوق المصدر والخط متاحة في `rights-font-review.json`. تبقى أدلة 06-L2 و06-L3 السابقة محفوظة بحالتها التاريخية.
