# طلب مراجعة إصدار مُلازَمَة

التطبيق للحفظ والتسميع الذاتي؛ المطلوب مراجعة واحدة للمنتج، لا مراقبة كل جلسة. لا توجد موافقة مفترضة أو توقيع جاهز.

راجع [الطلب المربوط بالأدلة](Approval-Request.pending.json)، [النص وفروق المرجع](../../docs/06l4/Content-Approval-Report.md)، [المنهج](../../docs/06l4/Self-Learning-Method.md)، [FSRS](../../docs/06l4/FSRS-Integration-Report.md).

المطلوب تحديد الطبعة والرواية/الطريق والرسم والترقيم والحقوق والخط وخريطة الكلمات والصفحات والمقاطع، وتفسير اختلافات المرجع، ثم قرار مكتوب على هذه الحزمة وعلى معيار الحفظ وسلم التسميع وحدود P0. لا يكفي اختيار «موافق» لملف غير مكتمل. يربط المهندس لاحقًا قرار المراجع وبيان الحزمة ببصماتها وجهة اعتماد مخولة وفق البوابات القائمة؛ لا تضف توقيعًا تجريبيًا أو تثق بمفتاح من نسخة المستخدم.
