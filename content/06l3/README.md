الأدلة التفصيلية `../../docs/06l3/evidence/content-comparison.json`، والتقرير `../../docs/06l3/Content-Approval-Report.md`. يحفظ `reference-receipt.json` مصدر الرد وبصمته وغياب إصدار dataset صريح. الرد الخام للمقارنة غير موزع في التسليم بسبب عدم إثبات إذن إعادة توزيعه ضمن حزمة بيانات؛ لا يُستعمل في التطبيق.

لإعادة المقارنة عند توفر ملف المرجع المخول المطابق للبصمة:

```sh
node scripts/content-compare06l3.mjs --reference /path/to/authorized-qpc-response.json
node node_modules/vitest/vitest.mjs run src/content/comparison06l3.test.mjs
```
