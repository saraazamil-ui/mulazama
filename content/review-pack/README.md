# مُلازَمَة — حزمة المراجعة المتخصصة للمحتوى

هذه حزمة عمل فارغة من الآيات. **لم تحصل مراجعة بشرية أو موافقة علمية.** لا تمنح موافقة للمحتوى بمجرد التوقيع على قالب غير مكتمل، ولا تستخدم البيانات الاصطناعية دليلًا على سلامة القرآن.

| المراجع المطلوب | المهمة | المستند الذي يودع |
|---|---|---|
| متخصص في القراءات والرسم والضبط | تحديد حفص والطريق إن صرح به المصدر، نظام العد، الطبعة، الضبط وعلامات الوقف | هوية ومؤهلات ونطاق المراجعة ومرجع الطبعة وسجل الفروق وقرار معلل |
| مراجع مصحف مستقل | مقابلة النص الكامل وخريطة الحدود على النسخة المحددة | نتائج المقابلة والملاحظات وإغلاق كل فرق؛ استقلال المرجع لا يفترض من اختلاف اسم الموقع |
| مسؤول الحقوق | حقوق النص والmetadata والخط وembedding والصوت/التفسير إن وجدا | نصوص التراخيص المرافقة وأذونات لازمة ونص النسبة المقرر |
| مهندس محتوى | البايتات والبصمات والإصدارات والمفاتيح والتقطيع والخرائط | إيصالات التنزيل وملفات المصدر الأصلية وتقارير المدقق والمقارنة |
| مراجع عرض وإتاحة | عرض التشكيل والمركبات والوقف، التكبير وعدم القص، فصل البحث عن الأصل | صور وبيئة متصفح/جهاز فعلية، فحص يدوي وقارئ شاشة موثق |
| مسؤول إصدار مستقل مخول | مطابقة الحزمة المراجعة للملفات الموقعة وتسجيل المفتاح | توقيع البيان وسجل الإصدار ومراجعة الثقة؛ لا مفتاح مولد داخل الاختبارات |

المواد المطلوبة قبل بدء المراجعة:

- ملف الناشر الأصلي، إشعار الحقوق، URL وخيارات التنزيل وتاريخه، SHA-256 للملف الخام، وعدم تعديل نهايات الأسطر أو Unicode.
- اسم طبعة محدد ومعرفها ومصدر العد وحدود السور وسياسة البسملة، لا مجرد «مصحف المدينة» أو رقم صفحة.
- خريطة صفحات/أجزاء/أحزاب/أرباع من الطبعة نفسها، إصدارها وبصمتها، وقواعد عبور الآية حدود صفحة أو جزء عند وجود ذلك.
- مخطط الكلمات وإصداره وبصمته، مواضع `(editionId,surah,ayah,tokenIndex)`، حدود شاملة/غير شاملة، وحدات الوقف والابتداء والربط المقبولة.
- خط محدد وبصمته ورخصة تضمينه، وبيان ما إن احتاج النص ترميزًا مخصوصًا بالخط. لا يضاف tatweel أو تغير علامة إلى الأصل لتحسين العرض دون مسار محتوى معتمد جديد.
- مقارنة مستقلة معللة، مع حالات اختلاف البسملة والضبط والوقف؛ لكل فرق نتيجة مراجعة، لا تسوية بالتطبيع أو محو العلامات.
- تحقق كامل من السور/الآيات والتسلسل والمفاتيح والخرائط والبصمات ثم المراجعة العلمية؛ النجاح الآلي لا يغني عن الثانية.
- ملف صوت مستقل اختياري فقط إن وُجد: الرواية والقارئ وحقوق التوزيع ومحاذاة الآيات والبصمات. لا يرث ترخيص النص. والتفسير مورد مستقل كذلك.

نقاط العناية عند مراجعة العرض: علامة الشدة مع الكسرة، الألف الخنجرية، علامات المد والوقف، التنوين، عدم تفكيك الحركات عن حروفها، عدم اختفاء علامات عند الحواف أو التكبير، فصل نص البحث الإملائي عن نص العرض، وعدم تسرب النص المخفي إلى شجرة الإتاحة أو الحافظة أثناء الاختبار.

تسجل النتائج في `scientific-review.template.json` بعد نسخ القالب إلى سجل حقيقي. تحفظ أسماء المراجعين ومؤهلاتهم وتواريخهم ونطاقاتهم وإصدار المحتوى وبصمته، ويترك غير المفحوص `null`. يبقى القالب `pending` وغير قابل للتفعيل. قرار التفعيل يمر عبر التوقيع وسياسة الإصدار الموثوقة، ولا يُستمد من هذا الملف التحريري.
