Node24+ وpnpm11.25.0 وPython3 وOpenSSL؛ القفل والتبعيات كماL1. لا node_modules أو أسرار أو سجلات مستخدمين في ZIP.

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
python3 scripts/verify-06l2.py --browser
pnpm dev
```

البديل مع Chrome المثبت: `PW_CHANNEL=chrome python3 scripts/verify-06l2.py --browser`. يحفظ المشغل كل نتيجة، ويعيد أدلة المراحل السابقة بعد حفظ المخرجات الجديدة ضمن L2. exit2 في تدقيق المحتوى والبوابات يعني حجبًا متوقعًا، وليس نجاح اعتماد. إعادة تشغيل المرجع تحقق ملفات الناشر المثبتة محليًا، ولا تجلبها من الشبكة كل مرة.
