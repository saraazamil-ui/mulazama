## تشغيل ومراجعة محلية

Node24+ وpnpm11.25.0. القفل والتبعيات لم يتغيرا. ZIP لا يتضمن node_modules أو ملفات مستخدمين. استخدم متصفحًا يدعم IndexedDB/WebCrypto وlocalhost أوHTTPS.

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
pnpm dev
```

التحقق الكامل:

```sh
python3 scripts/verify-06l1.py --browser
# عند استخدام Chrome المثبت بدل Chromium:
PW_CHANNEL=chrome python3 scripts/verify-06l1.py --node /path/to/node --browser
```

يسجل الأمر النتائج والمخارج، ويحفظ نواتج الاختبارات الموروثة داخل أدلة L1 ويعيد تقارير المراحل السابقة كما كانت. exit2 لأمر05-C يعني الحجب المطلوب، وليس اعتمادًا؛ نجاح مشغل الاختبارات لا يجيز نشرًا. المرجع الرسمي المحفوظ يتحقق محليًا من التوقيع والبصمات، ولا يجلب نسخة رسمية جديدة في كل تشغيل.

```sh
pnpm build
pnpm verify:build
pnpm preview
```

مخرجات dist للمعاينة المحلية. صفحات privacy.html وterms.html وsupport.html مسودات صريحة، ووسيلة الدعم والحسابات والاستضافة والنطاق غير معتمدة. راجع [متطلبات التشغيل والخصوصية](docs/06l1/Hosting-Privacy-and-Support.md) و[إجراءات الإصدار والتراجع](docs/06l1/Release-and-Rollback.md). لا إنتاج أو حسابات خارجية ضمن هذا التسليم.

تقارير06-E1 والمراحل السابقة أدلة تاريخية محفوظة داخل الحزمة. لم تتغير النصوص أو خوارزميات FSRS أو معاملاتها أو إصدارات الأحداث أو مخطط قاعدة البيانات أو سياسة05-C. المسار المصحح يظل مقارنة ظلية؛ انتخابه وترحيله واعتماد المحتوى أعمال معلقة في السجل الموحد.
