# مُلازَمَة — MULAZAMA · 06-L3

**الرحلة الهندسية المعزولة قابلة للتشغيل؛ التجربة القرآنية والإطلاق العام غير معتمدين.** يرتبط الإعداد والحفظ الذاتي والمراجعة والتصحيح والنسخ الاحتياطي الآن بالخدمات الفعلية وسجل الأحداث. المادة في الاختبار الصناعي ليست قرآنًا، وتبقى نسخة الموقع العادية محجوبة أمام الجلسات حتى استيفاء بوابات المنتج.

ابدأ من [التقرير النهائي](docs/06l3/Final-Report.md)، [الموانع](docs/06l3/Gate-Closure-Report.md)، [الاختبارات الفعلية](docs/06l3/Test-Report.md)، [إجراءات المالكة](docs/06l3/Owner-Actions.md). الأساس L2 ZIP وGit bundle؛ [إيصال المصدر ونسخة الاسترجاع](docs/06l3/evidence/source-receipt.json). لم يُستخدم مشروع جديد أو أساس أقدم.

Node24+ وpnpm11.25.0 وPython3 وOpenSSL. لا node_modules أو أسرار أو بيانات مستخدمين في التسليم.

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
python3 scripts/verify-06l3.py --browser
```

يمكن استعمال Chrome المثبت عبر `PW_CHANNEL=chrome`. يحفظ المشغل نتائج فعلية ويستعيد بايتات تقارير المراحل السابقة بعد نسخ المخرجات الجديدة إلى أدلةL3. exit2 في تدقيق المحتوى/بوابات05-C يعني حجبًا متوقعًا، لا اجتيازًا للاعتماد. قارئL2 المرجعي وFSRS مثبتان محليًا، ولا يحتاج التحقق جلبًا جديدًا.

لتجربة الرحلة الصناعية على جهاز المطور:

```sh
pnpm engineering:local
```

افتح `http://127.0.0.1:4178/engineering.html`. يفتح الخادم على loopback فقط، بقواعد بيانات اختبار جديدة ومعرّفات منفصلة. لا تنشر `dist-engineering`. هذا ليس قرآنًا ولا بيئة لاستقبال مشاركين. إعادة فتح المتصفح قد تنشئ معرف اختبار جديدًا؛ يمكن تصدير نسخة مشفرة من صفحة البيانات للاختبار.

```sh
pnpm build
pnpm preview
```

البناء العادي في `dist` لا يحتوي مدخل التفعيل الصناعي، ولا يمنح صلاحيات عبر URL أو التخزين أو نسخة احتياطية. [تعليمات النشر والتراجع](docs/06l3/Deploy-and-Rollback.md)، [المحتوى](docs/06l3/Content-Approval-Report.md)، [FSRS](docs/06l3/FSRS-Integration-Report.md)، [الأمن](docs/06l3/Data-Security-Report.md)، [الاستضافة](docs/06l3/Hosting-Readiness.md).

المسار المصحح اختيار إصدار صريح للسجلات الجديدة فقط؛ السجلات القديمة تحتفظ بمعناها، ولا ترحيل فعلي. **قارئL2 لا يقبل أحداث الإصدار المصحح الجديد**؛ تراجع الشفرة وحده غير صالح لهذه البيانات. نواةFSRS وأوزانها وP0 والنصوص الأصلية محفوظة. التقييمV1 ذاتي وليس شهادة إتقان، والبوابات لا تنتقل بين مستويات التفعيل تلقائيًا. لا نشر إنتاجي أو حسابات خارجية، وCI لا يتضمن خطوة نشر.
