# مُلازَمَة — MULAZAMA · 06-L4

**الرحلة الهندسية المعزولة قابلة للتشغيل؛ التجربة القرآنية والإطلاق العام غير معتمدين.** يرتبط الإعداد والحفظ الذاتي والمراجعة والتصحيح والنسخ الاحتياطي الآن بالخدمات الفعلية وسجل الأحداث. المادة في الاختبار الصناعي ليست قرآنًا، وتبقى نسخة الموقع العادية محجوبة أمام الجلسات حتى استيفاء بوابات المنتج.

تهيئة التطوير السحابي 08-A: [طريقة بدء المهام والتحقق وحدود الإعداد الدائم](docs/08a/Cloud-Readiness.md)، و[نتائج التنفيذ السحابي الجديدة](docs/08a/Verification.md). تظل 06-L4 النسخة الهندسية المرجعية، ولا تعني هذه التهيئة اعتماد المحتوى أو الإطلاق.

ابدأ من [التقرير النهائي](docs/06l4/Final-Report.md)، [الموانع](docs/06l4/Gate-Closure-Report.md)، [الاختبارات الفعلية](docs/06l4/Test-Report.md)، [إجراءات المالكة](docs/06l4/Owner-Actions.md). الأساس L3 ZIP و Git bundle؛ [إيصال المصدر ونسخة الاسترجاع](docs/06l4/evidence/source-receipt.json). لم يُستخدم مشروع جديد أو أساس أقدم.

Node24+ و pnpm11.25.0 و Python3 و OpenSSL. لا node_modules أو أسرار أو بيانات مستخدمين في التسليم.

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
python3 scripts/verify-06l4.py --browser
```

يمكن استعمال Chrome المثبت عبر `PW_CHANNEL=chrome`. يحفظ المشغل نتائج فعلية ويستعيد بايتات تقارير المراحل السابقة بعد نسخ المخرجات الجديدة إلى أدلة L4. exit2 في تدقيق المحتوى/بوابات 05-C يعني حجبًا متوقعًا، لا اجتيازًا للاعتماد. قارئ L2 المرجعي و FSRS مثبتان محليًا، ولا يحتاج التحقق جلبًا جديدًا.

لتجربة الرحلة الصناعية على جهاز المطور:

```sh
pnpm engineering:local
```

افتح `http://127.0.0.1:4178/engineering.html`. يفتح الخادم على loopback فقط، بقواعد بيانات اختبار جديدة ومعرّفات منفصلة. لا تنشر `dist-engineering`. هذا ليس قرآنًا ولا بيئة لاستقبال مشاركين. إعادة فتح المتصفح قد تنشئ معرف اختبار جديدًا؛ يمكن تصدير نسخة مشفرة من صفحة البيانات للاختبار.

```sh
pnpm build
pnpm preview
```

البناء العادي في `dist` لا يحتوي مدخل التفعيل الصناعي، ولا يمنح صلاحيات عبر URL أو التخزين أو نسخة احتياطية. [تعليمات النشر والتراجع](docs/06l4/Deploy-and-Rollback.md)، [المحتوى](docs/06l4/Content-Approval-Report.md)، [FSRS](docs/06l4/FSRS-Integration-Report.md)، [الأمن](docs/06l4/Data-Security-Report.md)، [الاستضافة](docs/06l4/Hosting-Readiness.md).

المسار المصحح اختيار إصدار صريح للسجلات الجديدة فقط؛ السجلات القديمة تحتفظ بمعناها، ولا ترحيل فعلي. **قارئ L2 لا يقبل أحداث الإصدار المصحح الجديد**؛ تراجع الشفرة وحده غير صالح لهذه البيانات. نواة FSRS وأوزانها وP0 والنصوص الأصلية محفوظة. التقييم V1 ذاتي وليس شهادة إتقان، والبوابات لا تنتقل بين مستويات التفعيل تلقائيًا. لم تُنشأ حسابات خارجية أو يُنشر الموقع في هذه المرحلة؛ CI لا يتضمن خطوة نشر.

النطاق الرسمي المعتمد: **https://mulazama.com**. يُستخدم في إعدادات التطوير والربط والنشر المستقبلية؛ لم تُثبت هنا ملكيته أو جهة تسجيله أو حالة ربطه. مراجع النطاق السابق في تقارير المراحل محفوظة للتاريخ ولا تُعتمد لإعدادات جديدة، ولم يُغيّر أي DNS أو تحويل أو خدمة مرتبطة به. العناوين البريدية في إعدادات التشغيل مقترحة وغير مفعّلة. حالة المعاينة الخاصة الحالية وإصدارها مثبتان في [سجل المعاينة](docs/preview-current.json)؛ اسم 05-A في الرابط تاريخي. نتائج 06-L4 التاريخية: 897 اختبارًا برمجيًا، و35+12 اختبار واجهة ورحلة هندسية، و4+2 دون اتصال، و3 للنشر والتراجع المحلي، و5 للعرض المحجور، و40 حالة FSRS؛ لا تثبت نجاح النسخة الحالية قبل إعادة التحقق.
