# مُلازَمَة — MULAZAMA · Phase 05-A

أساس هندسي مشتق من كود 04-B مع الاحتفاظ بتصميمه العربي RTL. **الحكم: غير جاهز لاعتماد 05-A أو الإطلاق** بسبب المحتوى ومطابقة مكتبة FSRS واختبارات المتصفح والأجهزة الأصلية. الحزمة ليست تطبيق iOS/Android أو نسخة متجر.

ابدأ من [تقرير الجاهزية](docs/05a/MULAZAMA-Phase-05A-Engineering-Readiness-Report.md)، ثم [مصفوفة R01–R30](docs/05a/requirements.md) و[العقود](docs/05a/contracts.md).

## تشغيل البناء المرفق

من مجلد المشروع:

```sh
python3 -m http.server 5184 --bind 127.0.0.1 --directory dist
```

افتح `http://127.0.0.1:5184`. على macOS يمكن تشغيل `start-mulazama.command`. لا تفتح HTML بصيغة file؛ التخزين وService Worker يحتاجان HTTPS أو localhost. بُني `dist` فعليًا؛ تعذر تشغيل متصفح البيئة بسبب منع فتح المنافذ. عند فشل التخزين لا تُنشأ ذاكرة مؤقتة بديلة ولا يُمسح السجل.

## التطوير والاختبار

يلزم Node.js 24+ وpnpm 11.25.0. ملف القفل محفوظ بلا مكتبات تشغيل جديدة. التثبيت الحالي حُاول وتعذر بسبب DNS؛ الاختبارات والبناء استخدما الاعتماديات الموجودة.

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm security:check
pnpm build
pnpm verify:build
pnpm dev
```

على جهاز يسمح بخادم محلي ومتصفح:

```sh
pnpm exec playwright install chromium
pnpm test:e2e
pnpm test:offline
```

يمكن استخدام `PW_CHANNEL=chrome pnpm test:e2e`. ستة اختبارات متصفح تشمل 12 فحص IndexedDB و19 شاشة × 3 عروض مع axe والنسخ والإعداد. اختبار offline منفصل يعمل على البناء. **لم تُجتز هذه الاختبارات في البيئة الحالية.** CI مكتوب وغير مشغل خارجيًا. أمر `pnpm readiness:production` يفشل صراحة لأن بوابات الإنتاج مفتوحة.

## الطبقات وما يعمل

| المسار | المسؤولية |
|---|---|
| `src/content` | بيان المحتوى وبصماته وتوقيع الاعتماد؛ قائمة الثقة فارغة |
| `src/core` | HME وP0 والحساب البحثي FSRS-6 والإصدارات |
| `src/application` | تحقق الأوامر، خدمات المنتج والتعلم، replay والاستئناف |
| `src/persistence` | IndexedDB والمعاملات والتشفير والنسخ والاستبدال |
| `src/platform` | التوقعات ومرشحو التنبيه ومنافذ الصوت |
| `src/App.tsx`, `components.tsx` | التصميم السابق مربوط بحدود الإنتاج |
| `src/**/*.test.*`, `e2e`, `e2e-offline` | اختبارات قابلة للتكرار |
| `docs/05a` | التقرير الحالي والمصفوفة والأدلة والمخاطر وتسليم 05-B |
| `tests/legacy04b`, المراجع والوثائق الأقدم | شواهد تاريخية، لا بيانات مستخدم |

الإعداد والتفضيلات وميزانية اليوم والتصريحات مرتبطة بسجل حقيقي، بلا LocalStorage أو مهام صناعية في الإنتاج. نواة التعلم وحالاتها وجدولتها وخدمات جلساتها اختُبرت بوحدات صناعية فقط؛ جلسات القرآن محجوبة حتى C01 معتمد. لا توليد تلقائي كامل لخطة على مصحف حقيقي بعد.

FSRS-6 الحالي حساب بحثي صحيح مقابل المرجع الحسابي؛ **ليس مكتبة ts-fsrs مثبتة أو مطابقة معتمدة**، و`approvedForProduction=false`. IndexedDB مكتوب ولم يُتحقق في متصفح؛ `MemoryEventStore` للاختبار فقط. النسخ مشفر ومختبر على المرجع المعاملاتي، ولا يثبت فقد الطاقة أو معاملات المتصفح. التوقعات تمتنع، ولا صوت أو تسجيل أو إشعارات نظام مفعلة.

الاختيار الحالي React Web ونواة TypeScript واحدة. Capacitor وSQLite مرشحان للهواتف في 05-B، ولم يثبتا أو يبنيا هنا. لا تعاد كتابة قواعد الحفظ في واجهات المنصات.

## المحتوى والخصوصية

لا نص قرآن مولد أو غير معتمد مرفق. البصمة والتوقيع لا يغنيان عن مراجعة علمية للنص والرواية والتقطيع والطبعة. لا تُفعّل جلسة قبل الحزمة المعتمدة.

المفتاح المحلي غير قابل للاستخراج ومحفوظ في IndexedDB؛ ليس Keychain/Keystore، ولا يحمي من XSS أو متصفح مخترق أو حذف الموقع. النسخ AES-GCM وPBKDF2 تحتاج كلمة استعادة من 12 وحدة UTF-16 على الأقل؛ فقدها يمنع فتحها. لا رفع بيانات أو تسجيلات. التصفير يحذف سجل التعلم ويغير الهوية ويبقي الإعداد الحالي؛ النسخ الخارجية لا تحذف تلقائيًا.

`mulazama.com` نطاق مستهدف فقط؛ لم يُشتر أو يُسجل أو يُفعّل أو يُنشر عليه موقع.

يمكن توليد معاينة الواجهات بعد البناء بالأمر `node scripts/build-inline-preview.mjs`. تستخدم ذاكرة مؤقتة معلنة، وتحافظ على بوابة المحتوى، ولا تغير مخزن الإنتاج. فُحصت الشاشات التسع عشرة والتنقل وتكبير النص في JSDOM؛ التقرير `docs/05a/preview-smoke-results.json` ليس اختبار متصفح أو جهاز فعلي.
