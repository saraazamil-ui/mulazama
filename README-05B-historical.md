# مُلازَمَة — MULAZAMA · Phase 05-B

مصدر وبناء ويب هندسي محدثان، امتداد لحزمة 05-A الفعلية دون إعادة بناء المشروع. **الحكم: غير جاهز.** لم يعتمد المحتوى القرآني أو تطابق مكتبة FSRS، ولم تجر اختبارات المتصفح الفعلي أو الهاتف. جلسات القرآن محجوبة في الخدمة والواجهة.

ابدأ من [تقرير الجاهزية](docs/05b/MULAZAMA-Phase-05B-Verification-and-Readiness-Report.md)، و[نتائج التشغيل](docs/05b/evidence/final-summary.json)، و[المصفوفة](docs/05b/Requirements-Matrix.md)، و[بوابات الإصدار](docs/05b/Release-Gates.md).

## المتطلبات والتثبيت

Node.js 24+، pnpm 11.25.0. جميع الاعتماديات المباشرة مثبتة الإصدارات في package.json والقفل. لم تضف هذه المرحلة اعتماد تشغيل جديدًا. محاولة التثبيت المجمد تعذرت بسبب DNS لسجل الحزم؛ استُخدمت الاعتماديات الموجودة لإعادة اختبار المصدر. لا توصف قابلية تثبيت نظيف بأنها متحققة.

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm security:check
pnpm build
pnpm verify:build
pnpm dev
```

الأوامر من جذر المجلد. أنشئ البيئة staging عبر `pnpm exec vite build --mode staging` بعد توليد بصمة المصدر وtypecheck؛ استخدم أصل موقع مستقلًا للتجربة. لا تشغّل بيانات الاختبار على أصل الإنتاج.

## مشاهدة البناء المرفق

```sh
python3 -m http.server 5184 --bind 127.0.0.1 --directory dist
```

ثم افتح `http://127.0.0.1:5184`. ويمكن على macOS تشغيل `start-mulazama.command`. لا تفتح index.html مباشرة بصيغة file؛ التخزين وService Worker يحتاجان localhost أو HTTPS. منع فتح المنافذ في بيئة التنفيذ الحالية لم يسمح بتشغيل متصفح فعلي. وجود البناء لا يثبت نجاح العرض أو offline. mulazama.com نطاق مستهدف؛ لم يُشتر أو ينشر عليه.

## الاختبارات المستقلة والبوابات

```sh
pnpm content:tools
pnpm content:audit
pnpm fsrs:conformance
pnpm readiness:production
pnpm exec playwright install chromium
pnpm test:e2e
pnpm test:offline
```

تدقيق المحتوى ومطابقة FSRS وبوابات الإنتاج تعيد رمز 2 حاليًا، أي **Blocked** وليس اختبارًا ناجحًا أو خللًا ينبغي تجاوزه. تعليمات جلب المرجع الثابت في تقرير FSRS؛ لا تضع package عشوائيًا في node_modules ثم تعتبره معتمدًا. المكتبة المطلوبة ليست مثبتة في هذه الحزمة.

المتصفح: Chromium افتراضيًا؛ يمكن `PW_CHANNEL=chrome pnpm test:e2e` على جهاز مناسب. ملفات E2E تتضمن 21 فحص IndexedDB وترحيل DB v2/v3، وحملًا صناعيًا اختياريًا 20000 حدث. لم تُنفذ هذه الحالات هنا. لا تمثل JSDOM أو MemoryEventStore متصفحًا أو SQLite أو جهاز هاتف.

## ما تغير

- تحقق صارم من مخططات أحداث المنتج والتعلم وإعادة التشغيل والنسخ؛ منع تكرار الفرصة والأمر والتغطية غير الصحيحة.
- ترحيل DB v3 صريح لفهرس عمليات حتمي، مع الحفاظ على الأحداث الخام ورفض الترحيل الغامض.
- التلميحات والانقطاع والإصدارات ومواعيد النموذج والسياسة والتخطيط محفوظة؛ التكرار لا يصبح إتقانًا.
- أدوات حجر وتدقيق المحتوى دون إدراج أي نص قرآني مولد أو حزمة غير معتمدة.
- أداة مطابقة مرجعية مستقلة لبايتات ts-fsrs@5.4.2؛ تظل محجوبة عند غيابها.
- بوابات إصدار موقعة ومربوطة بالبناء، وحجب من الخدمة، وفصل قواعد البيئات.

## الطبقات والتسليم

`src/content` للمحتوى، `src/core` للحساب والسياسات، `src/application` للعقود والأوامر وإعادة التشغيل، `src/persistence` للمخزن والنسخ، `src/platform` لمنافذ المنصات، `src/release` للأدلة والصلاحيات، و`src/App.tsx` للعرض السابق. `docs/05b` تضم التقارير العشرين والأدلة. `references` و`docs/05a` وREADME-05A-historical.md للتتبع، ولا تمثل نتائج تشغيل المرحلة الحالية.

المفتاح المحلي غير القابل للاستخراج داخل IDB يحمي الملف خارج المتصفح بحدود نموذج التهديد؛ لا يحمي من XSS أو شخص يستخدم جلسة متصفح مفتوحة. لا ترفع التسجيلات أو البيانات تلقائيًا. النسخ AES-GCM تعمل في اختبارات Node/المخزن المرجعي؛ استعادة المتصفح تبقى غير متحققة. لا يوجد مشروع iOS/Android أو بناء متجر في هذا التسليم.
