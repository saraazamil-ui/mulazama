# MULAZAMA — Phase 05-C Release Gates

**التاريخ:** 5 نوفمبر 2026 (الرياض). **السياق:** Web/Production. **الحكم:** غير جاهز؛ لا اعتماد بشري أو جهة ثقة أو توقيع إنتاجي أضيفت.

## ما أعيد اختباره

`evidence/release/security-release-tests.json`: 63 Passed، صفر Failed، صفر Pending. تضم المجموعة 19 اختبار بوابات و4 بصمة مصدر واختبارات خدمة المنتج والنسخ؛ العدد متداخل مع المجموعة النهائية ولا يضاف إليها. RG02/03/04/05/06/07/08/09/10 تكشف التكرار والعبث والسياق والوقت والتجاوز وغياب مرجع/مراجعة. RG11/12 ترفضان capability مزيفة وتمنعان كتابة أمر تعلم قبل الإذن. RG19 يمنع سياق إنتاج في staging، وSH02 يثبت إبطال الدليل عند تغيير المصدر أو القفل أو البناء.

`evidence/release/gates-initial.json`: سياسة mulazama-release-policy-05b.1 على النسخة عند هذا التشغيل؛ عشر بوابات Blocked، trustAnchorCount=0. بصمة المصدر لهذا التشغيل أولية أثناء الدمج؛ يعتمد التقرير النهائي ناتج إعادة توليد السياق بعد الدمج. لا تواقيع افتراضية أو جهات اعتماد مضافة. تواريخ/بيئة كل تشغيل في JSON، والتوقيعات الحالية غير موجودة.

## تعديل أداة التقرير

أضيف `--phase 05-C` لأداة verify-release مع بقاء default05-B للتوافق، وإنشاء مجلد ملف `--output` المحدد فعليًا. يمنع ذلك نسب دليل 05-C إلى مرحلة05-B أو فشل إخراج إلى مجلد جديد. لا يغير سياسة التحقق أو الثقة أو شروط فتح الوظائف. الأمر:

```sh
node scripts/generate-release-context.mjs
node scripts/verify-release.mjs --phase 05-C --output docs/05c/evidence/release-gates-final.json
```

الخرج2 يعني Blocked. لا تعني نتيجةPassed مستقبلية إذن نشر عام أو اعتماد متجر أو إثبات فاعلية تربوية.
