### مضاهاة تنبيهات المصدر

راجعنا التنبيهات الأصلية في 5 نوفمبر2026. [تنبيه Vitest الأصلي GHSA-5xrq](https://github.com/vitest-dev/vitest/security/advisories/GHSA-5xrq-8626-4rwp) يربط الأثر بخادم UI/API مكشوف أو UI/Browser Mode على Windows، ويذكر تصحيح3.2.5/4.1.0. استجابة registry المستلمة تصنف `<3.2.6`؛ سُجل الاختلاف ولم يعمم أثر الخادم على حزمة React المتصفحية.

[تنبيه Tinypool الأصلي GHSA-85c8](https://github.com/tinylibs/tinypool/security/advisories/GHSA-85c8-ppgw-ccpr) يصف prototype pollution سابقًا مع run options ونسخة مصححة2.1.2، ويصنفهHigh؛ استجابة registry صنفتهCritical. نقلت أعداد registry كما هي ولم نخترع CVSS أو ندّع نجاح استغلال محلي. كان معيار المعالجة أشد نطاقات registry وحالة audit بعد الترقية؛ التفاصيل الأصلية محفوظة. لم يتم تشغيل exploit ضد جهاز أو خدمة.

## التشفير والمفاتيح والاستعادة

التنفيذ يستخدم AES-256-GCM وPBKDF2-SHA256/600000، salt16بايت وIV12بايت عشوائيين ومصادقة الرأس وإغلاق مخطط الملف. اختبارات كلمة خاطئة وعبث/بتر وإصدار غير مدعوم وUTF غير سليم ومحتوى replay مخالف وCAS وفشل الاستبدال المرجعي تعاد ضمن مجموعات backup/release. تقرير Browser-Persistence-and-Backup-Verification.md يحدد ما حدث في IndexedDB فعليًا؛ لا تستبدل هذه الاختبارات دليله.

المفتاح المحلي غير القابل للاستخراج يمنع exportKey حين يطبقه WebCrypto، لكنه لا يمنع XSS من طلب فك التشفير أو قراءة البيانات المفكوكة تحت origin. لا يوفر جهازًا مفتوحًا أو إضافة متصفح خبيثة أو برنامج جهاز خبيث ضمانًا إضافيًا. كلمة ضعيفة تعرض ملف النسخة لتخمين دون اتصال؛ لا يوجد استرداد سر مفقود أو ادعاء محو مضمون من ذاكرةJS.

## حدود الثقة والنشر والخصوصية

- سجل الثقة الإنتاجي فارغ، ولا مفاتيح مراجعين أو توقيعات اعتماد جديدة. دليل اختبار صناعي لا يمنح إذنًا بشريًا. RG11/12 يرفضان قدرة مزورة ويمنعان كتابة أمر قبل الإذن.
- تحقق البصمات والسياق والنسخ والمنصة والمحتوى وفهرس الوحدات يحمي من إعادة استخدام دليل لشيفرة أخرى؛ لا يثبت صدق التقرير إذا كذب صاحب صلاحية موثوق.
- لا رفع تلقائي لبيانات المستخدم أو التسجيلات ولا حساب سحابي. لا إذن صوت أصلي أو إشعارات أصلية متكاملة. اختبارات المرحلة صناعية.
- حذف التطبيق محو منطقي للأحداث والفهرسة وفق نطاق الخدمة، وليس محوًا جنائيًا من وسيط التخزين أو نسخ النظام أو ملفات سبق تصديرها. لا تمسح طلبات الحذف نسخًا خارجية تلقائيًا.
- CSP وHTTPS وأمن سلسلة النشر وفصل صلاحيات مفاتيح الاعتماد والتدوير/الإلغاء والمراجعة الاختراقية لم تعتمد؛ لا يوجد موقع عام منشور في هذه المهمة أو تسجيل مثبت لـmulazama.com.
