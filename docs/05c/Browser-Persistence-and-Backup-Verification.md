## مراجعة أمن النسخ

الكود يستخدم AES-256-GCM وtag 128 بت؛ PBKDF2-SHA256 بـ600000 دورة؛ salt عشوائي 16 بايت وIV عشوائي 12 بايت لكل تصدير. الرأس canonical مصادق عليه كـAAD. استيراد واشتقاق المفاتيح `extractable:false`. الحد الأدنى لكلمة المرور 12 نقطة Unicode، والحد الأعلى 1024 بايت UTF-8، مع رفض UTF-16 غير القابل للتحويل العكسي. تُرفض الحقول الزائدة والإصدارات والتشفير/KDF غير المدعومة، والملف المبتور والبصمة المصادقة الخاطئة قبل الاستبدال.

نجاح اختبارات الكلمة الخاطئة وتعديل الرأس/الحمولة والصيغ غير المدعومة وتدقيق replay يثبت حالات الرفض المحددة في Node فقط. لا يثبت اختبار اختراق أو تحليلًا تشفيريًا مستقلًا. عدد الدورات ثابت للصيغة الحالية؛ لم تقس تكلفة الاشتقاق على أجهزة الهاتف.

الاستعادة تتحقق قبل `replace` وتستخدم expected revision لمنع الكتابة فوق تغييرات متزامنة. استبدال ملف مشروع كامل بآخر صحيح وكلمة مروره لا يمكن تمييزه دائمًا بتشفير الملف وحده؛ يلزم أن يراجع المستخدم ملخص الهوية والحجم والمحتوى قبل الاستبدال. لا يوجد ادعاء توثيق مرسل خارجي.

مفتاح المتصفح غير القابل للاستخراج لا يمنع XSS من استدعاء decrypt عبر الجلسة، أو شخصًا يستخدم جلسة مفتوحة؛ النسخة تحتاج سرًا قويًا يحفظه المستخدم. حذف الصفوف لا يثبت محو نسخ المتصفح أو الجهاز أو النسخ الخارجية. لم يُثبت عزل سر المستخدم عن إضافة خبيثة أو جهاز مخترق.

## نواقص لا تغطيها الفحوص القائمة

الأوضاع الخاصة للمتصفح، امتلاء حصة حقيقية، إغلاق browser process بعد commit، إعادة بناء جلسة تعلم فعلية عبر UI، سياقان/تبويبان مستقلان، cold offline start، واستعادة نسخة مشفرة داخل المتصفح: **Not Tested**. لا تُغلق بوابة تخزين قبل تنفيذها على مصفوفة المنصات المدعومة. اختبار جهاز أو browser واحد لا يثبت سلوك جميع الأجهزة أو انقطاع الطاقة الفيزيائي.
