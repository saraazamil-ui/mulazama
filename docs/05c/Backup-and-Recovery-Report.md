# MULAZAMA — Phase 05-C Backup and Recovery

تقرير الاختبارات المجمعة وحدود البيئة: [Browser-Persistence-and-Backup-Verification.md](Browser-Persistence-and-Backup-Verification.md). اختبارات Node/WebCrypto والمخزن المرجعي لا تُعد إثبات IndexedDB أو انقطاع طاقة جهاز. بيان الجسر بين سجلي المنتج والتعلم في [HME-Integration-Report.md](HME-Integration-Report.md).

التشفير AES-256-GCM، اشتقاق PBKDF2-SHA256/600000، salt16 وIV12 عشوائيان، والرأس مصادق عليه. المخططات المغلقة ترفض الإصدار غير المدعوم والرأس الزائد والحمولة المعدلة والبتر وكلمة المرور الخاطئة وUTF غير السليم والسجل غير القابل لإعادة التشغيل. يستلزم الاستبدال تأكيدًا وCAS ولا يجوز حذف الأصل قبل نجاح المعاملة.

G05 تظل Blocked حتى نجاح الاستعادة الذرية على مخزن المتصفح الفعلي وإعادة الفتح والتراجع ورفض الملف المعدل والتحقق من عدم مضاعفة الأحداث. حماية المفتاح غير القابل للاستخراج لا تمنع XSS أو استخدام جلسة مفتوحة. الحذف منطقي ولا يشمل تلقائيًا الملفات المصدرة خارجيًا.
