# التشغيل والاستضافة — 06-L3

**لا استضافة خارجية أو نطاق أو بريد معتمد ضمن هذه المرحلة.** اختبارات الرحلة الهندسية المحلية لا تمنح إذن التجربة القرآنية أو النشر العام. المالكة هي المشغلة من السعودية؛ آخر إفادة منها أنها لم تنشئ حسابات ولديها وسيلة دعم خاصة لم تحددها للنشر.

| النطاق | الحالة والدليل | المطلوب قبل الاستخدام الفعلي |
|---|---|---|
| بيئة هندسية منفصلة | بناء ومدخل اختبار وIndexedDB وcache منفصلة، بمادة صناعية غير قرآنية؛ [حدود العزل وoffline](Data-Security-Report.md) | تبقى على loopback؛ لا ترفع الحزمة الهندسية للمشاركين |
| البناء والمعاينة | إعدادات Vite والبناء والأصول موجودة؛ [أداة البناء الهندسي](../../scripts/build-engineering06l3.mjs) و[رؤوس الأمان](../../deployment/headers.example) | ربط المرشح المختبر ببيئة مخولة وإثبات تطبيق الرؤوس فيها |
| HTTPS وDNS | لا شهادة عامة أو إعداد DNS منفذ؛ استعلام L2 أعاد NXDOMAIN وقت فحصه، ولا يثبت الملكية أو إتاحة الشراء | إثبات ملكية mulazama.com، ثم قيم المزود الفعلية وشهادة موثوقة |
| البيانات والتراجع | نسخ مشفرة واختبارات استعادة محلية؛ القارئ القديم يرفض سجل المحرك الجديد | نسخة بيانات وقارئ متوافقان؛ لا يكفي تنزيل شفرة L2 للتراجع عن قاعدة جديدة. [الدليل](FSRS-Integration-Report.md) |
| الدعم والخصوصية | صفحات محلية ومسودات قائمة؛ لا قناة عامة مجربة أو مزود مراقبة خارجي | اسم العرض وقناة الدعم ومراجعة السياسة حسب المعالجة والموردين الفعليين |
| التجربة المغلقة | لا staging مستضاف مخول أو تجربة بشرية | بيئة مقيدة الوصول، محتوى ومحرك معتمدان، واختبار تحديث وتراجع على أصلها |

لم تضاف أسرار أو متغيرات اعتماد خارجية إلى الشفرة. لا توجد قيمة DNS أو اسم مشروع استضافة يجوز اختلاقه الآن. تبقى المراقبة محلية؛ أي مزود أعطال لاحق يحتاج إعدادًا يمنع إرسال النص والسجلات الشخصية دون ضرورة وموافقة مناسبة. التخزين دون اتصال ليس نسخة احتياطية من بيانات الحافظ.

إجراءات المزود العامة محفوظة في [دليل L2](../06l2/Deploy-and-Rollback.md)، مع قيد توافق البيانات أعلاه. التنفيذ الخارجي يحتاج حسابًا وتفويضًا؛ لا نجاح CI أو رابط معاينة يفعّل الإنتاج تلقائيًا. [إجراءات المالكة المختصرة](Owner-Actions.md).
