# التجربة القرآنية المغلقة — خطة 06-L3

**لم تُنفذ ولم يُدعَ مشاركون.** نجاح رحلة صناعية في بيئة هندسية منفصلة لا يفتح هذه التجربة. تبدأ بعد اعتماد نص المنتج والمنهج والحساب وسلامة البيانات، وتجهيز معاينة مستضافة مقيدة وخصوصية ودعم، وصدور موافقة صريحة للتجربة.

العينة المقترحة10–20 بالغًا موافقًا، تشمل مبتدئين وأصحاب محفوظات ومسار الجمع. التسميع ذاتي، ولا يلزم معلم لكل جلسة. يلاحظ الفريق سهولة الاستخدام وسلامة التسجيل، ولا يصف الدرجة الذاتية بأنها شهادة إتقان أو قياس مستقل للتلاوة.

| المهمة | الهدف المحدد قبل التجربة |
|---|---|
| الإعداد وأول ورد فعلي |90% على الأقل بلا مساعدة؛ تُذكر أعداد كل فئة |
| حفظ النتيجة وتصحيحها وإعادة التحميل |100% سلامة أحداث؛90% يفهمون معنى التقييم الذاتي |
| الانقطاع والاستئناف | صفر فقد بيانات أو جدولة غير مفسرة؛90% ينجزون المهمة |
| فائدة الورد، من1 إلى5 |80% يمنحون4 أو5 مع ملاحظاتهم |
| عودة اختيارية بعد7 و14 يومًا |60% و50%؛ مع توضيح المنسحبين والمفقودين دون ضغط |
| الهاتف والإتاحة والخصوصية | صفر عائق حرج؛ جهاز فعلي ولوحة مفاتيح وقارئ شاشة بشري |

يسجل لكل مهمة رمز المشارك والفئة وبصمة الإصدار والجهاز والزمن وعدد التفاعلات والمساعدة والنجاح أو التعذر وسببه. يُقاس فتح الموقع→بدء الورد، وانتهاء التسميع→إقرار حفظ النتيجة؛ لا تستخدم نتيجة هندسية بديلًا عن القياس البشري. لا تغيّر الأهداف بعد الاطلاع على النتائج.

تؤخذ موافقة واضحة على الملاحظة والمتابعة، وتحدد جهة التواصل والغرض والمدة والانسحاب قبل جمع البيانات. لا تسجيل صوت أو شاشة افتراضيًا، ولا نقل سجل الحافظ الخام إلى CI. توقف التجربة عند فقد بيانات أو تسريب أو نص غير مطابق أو تجاوز بوابة، ثم تعالج المشكلة ويعاد الاختبار المتأثر قبل الاستئناف.

بعد اليوم14 يصدر تقرير بالأعداد الفعلية والقيود والمشكلات وحلولها. هذه عينة أولية لقابلية الاستخدام والملاءمة، وليست إثباتًا إحصائيًا عامًا للفاعلية. يظل الإطلاق العام معلقًا على حل الحرج واستيفاء بقية الشروط وموافقة نشر مستقلة. التفاصيل الموروثة والمقاييس نفسها في [بروتوكول L1](../06l1/Closed-Trial-Plan.md).
