## دليل المتصفح دون اتصال

راجعت شفرة وسجل تنفيذ `e2e-journey-offline/journey-offline06l3.spec.ts`: **حالتان منفذتان، نجحتا، صفر فشل أو تجاوز**. اختبرت النسخة الهندسية المبنية الحفظ والمراجعة الذاتية والتصحيح، وتصدير نسخة مشفرة واستعادتها بعد تغيير فعلي، ورفض كلمة المرور الخاطئة، وثبات الوقائع بعد إعادة التحميل دون اتصال. تقرأ أداة التحقق قاعدة UUID التي أنشأتها الواجهة فقط، بمعاملات قراءة، وتغلق كل سياق اختبار جديد.

الخدمة مقيدة بـ`127.0.0.1:4178`، والعامل الخدمي يستعمل بادئة cache مستقلة ويخزن أصول الواجهة دون أحداث التعلم. قائمة أصول الخدمة ثابتة، ولا يقدم مسارًا عشوائيًا من القرص. راجعت هذه الحدود في `scripts/build-engineering06l3.mjs`؛ لم يكن ذلك اختبار اختراق مستقلًا للخادم.

[النتيجة الخام](evidence/journey-offline-browser-results.json)، [ملخص الأمر وحدود البيئة](evidence/journey-offline-summary.json). مادة الجلسة صناعية غير قرآنية؛ لم يُختبر مستخدم حقيقي أو نشر عام أو HTTPS خارجي أو فقد طاقة فعلي. هذه الحالتان جزء من إجمالي اختبارات الرحلة دون اتصال في التقرير العام ولا تجمعان مرتين.

قدرة التنفيذ الحالية موسومة داخل WeakSet؛ كائن مزور أو اختيار واجهة لا يمنحها. سجل جهات الاعتماد مبني مع الشفرة وليس مستوردًا من نسخة المستخدم. بوابات05-C تتحقق من السياق ومدة الاعتماد وأدلة كل بوابة، وتبقى authority registry والتواقيع الفعلية غير متوفرة حتى اعتمادها. تعديل نتائج متوقعة أو وضع توقيع تجريبي في المنتج لا يغلق هذه الشروط.

## حدود التكامل التي روجعت واختُبرت

1. اختيار `CompositeApplication` لا يحدث قبل authorize، لأنه قد ينشئ أول واقعة تعلم. المسار المحجوب يستخدم مالك التاريخ للقراءة دون إنشاء HME تلقائيًا.
2. ربط الحساب المصحح بنسخة أحداث صريحة وبنفس `versionsDigest` المعتمد؛ لا تعيد بيانات النسخة القديمة تفسير نفسها بصمت.
3. استعادة النسخة المشفرة تتحقق من كل الوقائع وإصداراتها وصلاحية الوحدات قبل الاستبدال الذري. إلغاء الاستعادة أو كلمة مرور خاطئة لا يغير السجل.
4. حذف التعلم المؤكد لا يسمح لتبويب قديم بإعادة الوقائع؛ يلزم CAS وإعادة قراءة. قاعدة الاختبار لا تستعمل اسم قاعدة الإنتاج أو قيمة يرسلها query.
5. أثناء التسميع يغيب النص من DOM وإمكانية الوصول، والكشف يسجل واقعة قبل عرضه؛ إخفاء CSS وحده لا يكفي.
6. نتيجة الحفظ لا تظهر قبل إقرار المعاملة. التكرار والتصحيح لا ينشئان مراجعتين لنفس الفرصة. أية بيانات مصطنعة تظل معلنة ولا تصبح أدلة تعلم حقيقية.
7. غياب ملفات المحتوى المحجورة ومدخل الاختبار والصلاحية الصناعية من dist العام وcache الإنتاج شرط بناء مستقل؛ يثبت بواسطة فحص الحزمة النهائي، ولا يُستنتج من فحص خادم التطوير.

## البيانات والخصوصية

نتائج التسميع ذاتية؛ لا يُشترط معلّم خارجي لكل جلسة ولا توصف النتيجة بأنها تقييم مستقل أو شهادة إتقان. مراجعة سلامة إصدار الموقع مختلفة عن مراجعة الحافظ اليومية.

السجل المحلي مشفر في IndexedDB، والنسخة المحمولة مشفرة بكلمة استعادة؛ مفتاح الجهاز لا يحمي من شفرة خبيثة تعمل من الأصل نفسه أو متصفح مفتوح. cache العمل دون اتصال يحفظ أصول التطبيق ولا يغني عن تصدير نسخة بيانات. لم يضف هذا الفحص تسجيل صوت أو إرسال سجلات أو مزود تحليلات.

تبقى هوية الدعم العامة وسياسة المعالجة ومراجعة البيئة الفعلية والحقوق والمتطلبات المحلية بحاجة إلى حسم قبل تجربة المستخدمين. مسودة الخصوصية ونتيجة صفر تنبيهات لا تثبتان الامتثال أو توقيعG09. الإجراءات الخارجية القصيرة وقرار الجاهزية يوحدهما تقرير المرحلة النهائي.
