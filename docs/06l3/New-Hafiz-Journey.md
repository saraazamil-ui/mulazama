# رحلة الحافظ الجديد — 06-L3

**نجحت رحلة صناعية كاملة عبر المتصفح؛ لم تنفذ رحلة قرآنية معتمدة.** حالاتL3J01 وL3J03 وL3J04 وL3OFFJ01 تشغّل React وHME والحساب المصحح وIndexedDB الفعليين، في قواعد UUID معزولة وبمادة مصرح على الشاشة بأنها ليست قرآنًا.

المسار المنفذ: فتح المدخل → إعداد في3خطوات → هدف ووقت وأيام → الرئيسية → بدء الورد → تكرار → إخفاء النص والتسميع الذاتي → اختيار وصف نتيجة → تأكيد الكتابة → إعادة التحميل → متابعة التالي وموعد التعاهد. لا حقن أحداث لتمرير الرحلة؛ قرئت قاعدة الاختبار للتحقق فقط. أحداث النسخة المصححة محفوظة؛ إعادة التحميل لا تضيف تسميعًا. انقطاع التسميع يطلب محاولة جديدة ويحفظ الأصل، وكشف النص حدث لا يلغيه اختيار «بسهولة».

| التفاعل | L2 | L3 المعزول |
|---|---|---|
| الإعداد المعتاد |3خطوات منفذة؛ الجلسات محجوبة |3خطوات باقية؛ دون نموذج جديد |
| من الرئيسية إلى نشاط متاح | غير ممكن |نقرة واحدة |
| من نهاية التسميع إلى حفظ وصف النتيجة | غير ممكن |نقرة واحدة على وصف صريح؛ لا إدخال نسبة أو إعادة عدد كلمات |
| التصحيح الاعتيادي | لا رحلة جلسة قابلة للتشغيل |نقرتان: صحّح النتيجة ثم الوصف الصحيح |

سيناريو الإعداد الآلي الافتراضي استعمل5تفاعلات ظاهرة: بدء الإعداد، التالي، التالي، اختيار السبت لأنه خارج الأيام الافتراضية، الحفظ. اختيار هدف/وقت غير افتراضي يضيف تفاعلاته؛ هذا تعداد للسيناريو المنفذ لا قياس بشري عام.

نجح الحفظ وإعادة التحميل دون اتصال على البناء الفعلي. فحص320px ولوحة المفاتيح وaxe آلي؛ لم يختبر مستخدم حقيقي أو قارئ شاشة بشري أو جهاز هاتف فعلي. المواد المعتمدة لا تستبدل بالنص الصناعي: يبقى الاستخدام القرآني متوقفًا على [اعتماد المنتج](Content-Approval-Report.md).
