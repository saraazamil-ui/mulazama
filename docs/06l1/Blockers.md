# الموانع المتبقية — قرار غير جاهز

المصدر التنفيذي الوحيد للأعمال وأصحاب القرارات وشروط الأدلة هو Launch-Backlog.json؛ هذه خلاصة مرتبة لا سجل مواز.

1. **L01/L02 — المحتوى والمعيار:** لا بصمة محتوى معتمدة ولا كتالوج وحدات موثوق، ولا اعتماد متخصص لمعيار الحفظ والتسميع. يمنع تشغيل جلسات القرآن ويمنع نسب الحفظ، لا يمنع حفظ الإعداد والتصريحات.
2. **L03/L04 — الجدولة:** المصحح مطابق40حالة لكنه غير منتخب للكتابة ولا مرحّل. يلزم قرار صريح وخطة أثر واستعادة معتمدة؛ لا يغير هذا التسليم المفسر التاريخي أو الأوزان.
3. **L05/L06 — القيمة الأساسية:** عقد نشاط يوم بمعرف ثابت وربط النتيجة والوحدة والخطة والعودة المرنة غير معتمد. لذلك لا ورد حقيقي من البداية للنهاية ولا توصية تالية خوارزمية، ولا يسوّق الوعد «يعرف ما حفظته وينظم وردك» كوظيفة مكتملة.
4. **L09–L11 — أدلة المرشح:** الاختبارات المحلية لا تستبدل اعتماد05-C أو الأمن المستقل أو أجهزة فعلية أو قارئ شاشة أو مراجعة علمية. G01–G10 محجوبة.
5. **L12–L15 — التشغيل:** المشغّلة مالكة المشروع من السعودية؛ لا حسابات أوremote/استضافة معتمدة، ولا إثبات ملكية النطاق أو قناة دعم معلنة. السياسات مسودات، والتراجع الخدمي غير مجرب. المستودع المحلي والفروع لا تعني حمايةremote.
6. **L16/L17 — مستخدمون وإطلاق:** صفر مشاركين حتى الآن. الخطة تحدد المقاييس مسبقًا؛ لا شهادات ولا نتائج مختلقة. إطلاق عام يحتاج استيفاء المعايير وموافقة منفصلة.

المتاح الآن مراجعة هندسية محلية مع الإعداد وذاكرة وصفية واقعية ونسخ محلية. قرار «جاهز للتجربة» لا يصدر حتى تغلق تبعيات مرشح التجربة بأدلتها، ثم الاختبار البشري يسبق الإعلان العام.
