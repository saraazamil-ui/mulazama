# مصفوفة الوظائف الأساسية والجاهزية — 06-L1

المجموعة البرمجية الحالية [727/727](evidence/final-tests.json)، بصفر فشل أو تجاوز. اختبارات19 و28 ضمنها. نجحت [مجموعة المتصفح النهائية 31/31](evidence/final-browser-results.json)، بصفر فشل أو تجاوز أو flaky، فأغلقت L07/L08 محليًا. لا تعد هذه النتائج نجاحًا للجلسات أو اعتمادًا بشريًا أو علميًا؛ بقيت البوابات وقرار الإطلاق على حالهما. [المستودع المحلي](evidence/source-control.json) لا يثبت وجود remote أو حماية فروع بعيدة.


اكتمل كذلك [offline النهائي 4/4](evidence/final-offline-browser-results.json)، بصفر فشل أو تجاوز أو flaky، و[المرجع المصحح 40/40](evidence/fsrs/fsrs-investigation.json). أُصلح رجوع تنقل صفحات HTML الثابتة في service worker، ولم تتغير IndexedDB. هذه نتائج البيئة المسجلة فقط؛ لم ينفذ اختبار تثبيت على هاتف أصلي أو مراجعة بشرية لقارئ شاشة أو تراجع خدمة مستضافة.
