# مُلازَمَة — تشغيل المرحلة 10-B

النطاق الرسمي: https://mulazama.com. التنفيذ يضيف قارئ الصفحات وربطه برحلة الحفظ والمراجعة القائمة؛ لا يغيّر FSRS أو تفسير أحداث التعلم ولا يمنح إذن إنتاج.

## الوضع الحالي

القارئ البرمجي يدعم السور والأجزاء والصفحات، التنقل بالأزرار واللمس، حفظ الموضع واختيار نطاق الحفظ. يربط الاختيار بالخطة والجلسة القائمة، ويعيد الحافظ من خطة اليوم إلى الموضع المطلوب. الاختيار أو التصفح لا يسجل إتقانًا؛ نتيجة التعلم تمر بآلية التقييم الموجودة. كشف المصحف أثناء التسميع يمر بحماية المساعدة القائمة.

**عدد الحزم الرسمية التي نُزّلت: صفر.** عرض القرآن الحقيقي محجوب، و`runtimeMushafInput=null`. اختبارات القارئ تستخدم مادة صناعية معزولة لا تمثل القرآن ولا تدخل بناء المعاينة العادي. نجاح هذه الاختبارات لا يثبت سلامة مصحف أو اعتماده.

في فحص 8 نوفمبر 2026، رفض وكيل شبكة البيئة صفحات المجمع وحقوق DM وخدمة التضمين الرسمية بـ`CONNECT 403`. هذا قيد البيئة، لا إثبات تعطل الناشر. سجل الوصول والمواد المطلوبة في [official-acquisition.json](../../content/10b/official-acquisition.json).

## فحص أولي آمن دون استخراج

احفظ الأصل خارج `public` و`src`، ثم شغّل على ملف موجود فعليًا:

```sh
python3 scripts/inspect-official-archive10b.py ORIGINAL_ARCHIVE \
  --source-url https://dm.qurancomplex.gov.sa/ \
  --output NEW_RECEIPT.json
```

أضف `--published-sha256 CURRENT_PUBLISHER_SHA256` فقط بقيمة مثبتة من الناشر وقت الحصول على الملف. يقبل الأمر ZIP وTAR وTAR.GZ، ويسجل البصمة والحجم وقائمة الملفات ومرشحات ملفات الحقوق دون استخراج أو نسخ الأصل. حد الأصل والفك المعلن 2GiB، وعدد العناصر 20,000، ونسبة التوسع 200، ودليل ZIP المركزي 16MiB. يرفض المسارات الخطرة والتكرارات والروابط والملفات الخاصة والتشفير؛ ZIP64 وامتدادات TAR من نوع PAX/GNU غير مدعومة في هذا الفحص المحدود. لا يستبدل إيصالًا موجودًا.

نجاح الأمر يعني اجتياز **فحص القائمة والبصمة المقدمة فقط**. لا يثبت مصدر الملف أو CRC لكل محتواه أو صحة الآيات أو الحقوق، ولا ينتج اعتمادًا علميًا أو يفتح عرض القرآن.

## ما يلزم قبل تفعيل المحتوى

1. فحص الحزمة الفعلية والحقوق والطبعة والرواية وبصمات الأصول؛ لا تستخدم OCR أو نصًا مولدًا بديلًا.
2. تجهيز خريطة موثقة للسور والآيات والأجزاء والصفحات تربط الصور ببيانات الآيات الرسمية وبمعرفات التعلم الحالية، دون افتراض تطابق حزمتين مختلفتين أو إعادة تفسير السجل.
3. اجتياز فحوص المحتوى المستقلة: اكتمال وتسلسل الآيات، عدم الفقد والتكرار، توافق الخريطة والصور والطبعة، وبصمات الصور وأبعادها. ثم مراجعة بصرية/علمية مستقلة للصفحات والخريطة والحقوق.
4. إدخال الحزمة والخريطة وأدلة اعتماد المحتوى والصفحات الموقعة عبر مسار البناء المراجع وبوابات الاعتماد القائمة. لا يسمح URL أو التخزين المحلي أو النسخ الاحتياطي بتثبيت حزمة. يبقى إذن الإنتاج منفصلًا.
