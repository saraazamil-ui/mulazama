# مُلازَمَة V2.1.1 — تجربة الرحلة الخاصة

استكمال PR #19 على `codex/v211-private-journey`، مبني على السجل الموجود وعلى وثيقة V2.1.1 المرفقة. لا يحتوي هذا المسار على نص قرآني أو حسابات إنتاجية، ولا يفتح G01–G10.

## تجربة النسخة

```sh
pnpm install --frozen-lockfile
pnpm preview:v211
```

افتح `http://127.0.0.1:4182` **في متصفح البيئة التي تشغل الأمر**. الخادم مرتبط بالحلقة المحلية فقط؛ ليس رابط استضافة عامًا. في Codex Cloud توجد المعاينة داخل Chromium في لوحة Desktop المشتركة. يبدأ المستخدم بثلاثة مقادير اصطناعية، كل منها ثماني وحدات، ويمكنه إعلان بعضها أو البدء دون محفوظ. يحدد مدة التعاهد صراحة ثم يؤكد ملخص الخطة مرة واحدة.

جرّب الحفظ بهدفه الافتراضي 20 والتثبيت بهدفه الافتراضي 5، أو غيّرهما قبل بدء الجلسة. كل ضغطة تُحفظ قبل تحديث العدد؛ التوقف وإعادة فتح الصفحة يحفظان النطاق والهدف والعدد. التثبيت متاح عندما يوجد مقدار سابق كامل ومحفوظ ومتصل. يمكن تقديم **وقت التجربة فقط** من أعلى المعاينة إلى الجمعة ثم السبت لاختبار لقطة المراجعة وأهلية التعاهد؛ يبقى التاريخ التجريبي محفوظًا عند إعادة الفتح.

من التعاهد يمكن تسجيل المقدار كاملًا أو جزئيًا، ومنه وحدات محددة متفرقة. تبقى الأجزاء الأخرى على استحقاقها، ويظهر اقتراح موعد للمنجز فقط يحتاج تأكيدًا أو تعديلًا. تعديل الخطة يعرض فرق المواعيد قبل تأكيده، ويحفظ المواعيد اليدوية والسجل السابق. تنزيل الملخص يحوي الأحداث والإيصالات والإسقاط وoutbox المعلق؛ ليس نسخة سحابية ولا يتيح استيرادًا عامًا.

| `src/persistence/product-v211-store.ts` | معاملة IndexedDB واحدة للأحداث والإسقاط والإيصال وoutbox، ومنع التكرار وتعارض الإصدارات |

| `src/testing/v211.tsx` | مدخل معاينة خاص منفصل، لا يفتح قاعدة legacy ولا ينشئ صلاحية عرض قرآن |

إصدارات FSRS وقارئاتها وبياناتها القديمة محفوظة دون ترحيل دلالي. أرقام التجربة الجديدة لا تدمج بتاريخ FSRS ولا تدّعي الإتقان. التعاهد يستخدم المرشح الحسابي المتساوي المذكور صراحة في القسم 7 وأمثلة TA01–TA04؛ صياغة ترتيب التباعد الوصفية ليست مطابقة تمامًا للصيغة الحسابية، ولذلك لا يُقدَّم المحاكي بوصفه اعتمادًا تربويًا عامًا.

الحسابات الحقيقية والتحقق من البريد والمزامنة والاستعادة على جهاز آخر وحذف حساب الخادم غير مفعلة؛ تحتاج محول مزود معتمدًا. التخزين الجديد خاص بالبيانات الاصطناعية فقط، ولا يدعي تشفيرًا إنتاجيًا أو حفظًا سحابيًا. تصحيح تكرار الحفظ يعيد الإسقاط ويعلّق النطاقات المتأثرة، لكن محرر التصحيحات العامة وحل تداخل المواعيد تفاعليًا ليسا مكتملين. لا يُعدل موعد يدوي تلقائيًا عند التعارض.
