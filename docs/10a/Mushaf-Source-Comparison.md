## 1. المقصود بالمصدر الحالي

Tanzil Uthmani 1.1 موجود في المستودع **حزمة مراجعة محجورة** تحت `content/06l2/`، وليس نصًا قرآنيًا مفعلًا في المنتج. [إيصال الحصول](../../content/06l2/download-receipt.json) يسمي حالته `quarantined-not-approved`؛ [عقد C01](../../src/application/service.ts) يعيد `quranText:null` و`pageMap:null` و`editionId:"prototype-unverified"`. [مسودة بيان المحتوى](../../content/Content-Manifest.draft.json) تبقي `editionId:null`، وقائمة جهات الثقة في [ContentGate](../../src/content/content-gate.ts) فارغة. لا تُحوّل تسمية مرشح الفحص إلى هوية إنتاجية.

قُرئت تقارير 06-L4 الخاصة [بالمحتوى](../06l4/Content-Approval-Report.md)، [والمنهج](../06l4/Self-Learning-Method.md)، [وHME وFSRS](../06l4/FSRS-Integration-Report.md). لم يوجد تقرير 09-A في الملفات أو إشارات Markdown في نسخة `main` المشار إليها. أوضحت المالكة أنه تقرير تحليلي بعنوان «التصور العلمي والهندسي لتكامل مُلازَمَة مع خدمات التسميع الخارجية ومصحف المدينة النبوية»، أنجز في 2026-11-07 بمساحة مؤقتة ولم يحفظ في فرع أو PR، وأذنت صراحة بالمتابعة دون انتظار استعادته. لذلك نعتمد توجيهاتها الحالية، ولا ندعي قراءة نص 09-A أو التحقق من تفاصيله. غياب الملف **ليس شرط توقف لهذه الدراسة** بعد هذا الإذن؛ ولا يزيل موانع المصادر والحقوق المستقلة.

التوجيهات المرجعية المعتمدة لهذه المقارنة: صفحات رسمية بعد التحقق من الحزم والحقوق والمطابقة، وفهرس مستقل لا يغير هويات التعلم، والمحافظة على HME وFSRS والسجلات. الإحالات الاختيارية إلى «قرآن مباشر» و«تعاهد» من مكنون لا تعني وجود API أو نقل نتائج تعلم؛ لا يدخل تكامل خارجي في مقارنة المصادر أو في 10-A.

- بدايات صفحات XML مفاتيح سورة/آية، وليست صور صفحات ولا خرائط سطور أو إحداثيات كلمات. الصفحة 1 تبدأ بالمفتاح `1:1` والصفحة 604 بـ`112:1` وفق **هذا الملف**؛ لا تُرفع هذه المعلومة إلى إثبات طبعة رسمية معينة للمجمع.
- لم تُعد مراجعة بشرية للرسم والضبط والوقف، ولم يُعتمد خط أو تقطيع كلمات أو حزمة `ContentPackage` قرآنية. لم تكتب هذه الفحوص شيئًا إلى مصادر المحتوى أو ملفات الإنتاج.

## 3. مصفوفة المقارنة المطلوبة

## 4. تصميم المقارنة القابلة للتدقيق

1. **ثبّت الطرفين قبل التحليل:** أصل غير معدل لكل حزمة، SHA-256، حجم، رابط طلب ورابط نهائي، زمن الحصول، حقوق، وإصدار أداة الفحص. بصمة تحسب محليًا تثبت ثبات العينة؛ لا تثبت وحدها توقيع الناشر أو سلامة النص علميًا.
2. **تحقق من البنية أولًا:** فك الأرشيف في حجر، رفض مسارات الهروب والروابط غير الآمنة، فحص سلامة الأرشيف، جرد الملفات والأحجام، فك الترميز دون استبدال صامت. لا تشغل ملفات تنفيذية ولا ماكرو أو HTML من الحزمة أثناء الجرد. أصدر تقريرًا بالإخفاق ولا تبدأ المقارنة النصية عند تلف المدخل.
3. **ثبّت دلالة الهوية:** اختر بيان الرواية والطريق والعد والبسملة للمرجع، ثم أنشئ جدول توافق مفاتيح مستقلًا. المساواة العددية 6,236 لا تثبت وحدها وحدة الطبعة. اختلاف سياسة العد يمنع الربط التلقائي بالمفتاح ذاته.
4. **قارن السجلات الخام:** مفتاح `(surah, ayah)`، بصمة المقتطف، عدد نقاط الشفرة، وأول موضع اختلاف، مع المفقود والمكرر والزائد. لا يعتمد القارن على تشابه النص لإعادة ترتيب الآيات. إزاحات UTF-8 وUTF-16 ونقاط الشفرة حقول مختلفة وموسومة صراحة.
5. **صنّف دون تطبيع الأصل:** فرق غلاف أو ترميز؛ اختلاف تسلسل Unicode؛ اختلاف ضبط/وقف أو حرف؛ اختلاف رقم/زخرفة؛ اختلاف تخطيط صفحة/سطر؛ اختلاف تقطيع. يجوز حساب توصيف Unicode على نسخة في الذاكرة لشرح الفرق، لكن لا تستخدم مساواة بعد NFC/NFKC أو حذف العلامات دليل اعتماد، ولا تحفظ متنًا معدلًا بديلًا.
6. **افصل المطابقة النصية عن التخطيط:** صورة أو PDF لا يعطي نصًا دقيقًا بمجرد الاستخراج. OCR قرينة غير معتمدة فقط. استخرج خريطة الصفحات/الأسطر من مورد موثق إن توفر، ثم طابقها على ملفات الصفحات بالنسخة نفسها؛ كل اختلاف حدود يحتاج تسجيلًا مستقلًا.
7. **راجع كل المواضع المتأثرة:** لا يكفي فحص أول ووسط وآخر المصحف. راجع جميع المفاتيح وحدود الصفحات، وبدايات/نهايات السور والبسملة، والآيات الطويلة والممتدة، والعلامات والتراكبات. يغلق المختص الخلاف العلمي بقرار موثق مرتبط ببصمات المدخلات.
8. **احفظ النتيجة دون تسريب:** تقرير مشتق بالمعرفات والبصمات والفئات، وإصدار القارن، وقرارات المراجعة. لا تُضمّن نصًا أو خطًا أو صورًا في Git أو التسليم ما لم تثبت حقوق ذلك. نجاح المقارنة لا يفعّل ContentGate ولا يغير `productionReady=false` أو G01–G10.

### ما يعد فرقًا تقنيًا وما يحتاج مختصًا

| الملاحظة | الحكم الآلي المسموح | ما لا يحسمه البرنامج |
|---|---|---|

| اختلاف فصل الكلمات | اختلاف tokenization يحتاج crosswalk معتمدًا | تغيير `unit.words` أو P0 أو إسناد تاريخ نجاح إلى رموز جديدة |

[تحقق ترتيب المصدر](../../src/content/journey-order06l4.ts) يرفض العكس والتكرار والتداخل وتغيير الحدود، ويسمح بالفجوات المرتبة دون تسميتها متصلة.

بناء عليه:

- Mushaf Index طبقة ربط قراءة مستقلة؛ `mushafReleaseId` يحدد إصدار مورد الصفحات، و`sourceEditionId` يحمل قيمة `editionId` الأصلية للوحدة حرفيًا دون استبدالها. ينضم عبر جدول توافق مثبت ببصمات، ولا يستنتج الربط من رقم الصفحة أو عنوان الوحدة وحده.
- يحتفظ الربط بجميع معرفات التغطية الأصلية، وبترتيب المقاطع والفجوات. الآية قد تمتد إلى أكثر من سطر أو صفحة؛ علاقة الموضع ليست بالضرورة واحدًا إلى واحد. إذا لم يثبت موضع كلمة داخل الصفحة، يبقى الربط على مستوى الصفحة ويعرض نطاق الورد خارجها.
- فرق التقطيع لا يسمح بتغيير `unitId` أو `unit.words` أو coverage أو إعادة تشغيل سجل قديم بمعنى مختلف. لا تُنقل هوية FSRS المؤلفة من المستخدم والوحدة والطبعة وملف P0 إلى هوية المصحف المرئي.
- تعذر الربط أو اختلاف إصدار المورد ينتج حالة `unmapped`/رفضًا معلومًا؛ لا يعرض صفحة تقريبية بوصفها الموضع الصحيح، ولا ينشئ نتيجة نجاح أو event أو ترحيل قاعدة بيانات.
- النص البديل لقارئات الشاشة يحتاج مصدرًا معتمدًا وربطًا دقيقًا إلى الصفحة. لا يصبح Tanzil النص البديل الافتراضي لصور المجمع لمجرد توافق أسماء السور أو مجموع الآيات.

العقد التفصيلي والأمثلة الصناعية في [Mushaf-Index-Architecture](Mushaf-Index-Architecture.md)، وضبط كشف النص أثناء التسميع في [Mushaf-Viewer-UX](Mushaf-Viewer-UX.md).

## 6. المقارنة التاريخية لا تسد نقص المرجع الرسمي

تقرير 06-L3 المحفوظ قارن مرشح Tanzil برد API يحمل `text_qpc_hafs`: 6,236 مفتاحًا، و0 مساواة حرفية و6,236 اختلافًا، دون مفاتيح مفقودة. تضمنت الاستجابة أرقام آيات وعلامات/تمثيلات مختلفة. هذه **نتيجة تاريخية** راجعها 06-L4 ولم تُعد شبكة المقارنة في 10-A، وليست حكم تحريف، ولا دليل تنزيل مباشر لحزمة المجمع أو إثبات إصدارها واستقلال نسبها.

الرد الخام غير موزع في المستودع بسبب عدم إثبات حقوق تخزينه وإعادة توزيعه؛ [إيصال المرجع](../../content/06l3/reference-receipt.json) و[المقارنة التاريخية](../06l3/evidence/content-comparison.json) لا يعوضان الملف الأصلي المخول. لا يستخدم أي مزود غير رسمي بديلًا لتجاوز تعذر الوصول الرسمي في 10-A.

## 7. إعادة إنتاج الفحص المحلي دون تعديل النص

الأوامر التالية تقرأ الملفات وتطبع نتائج فقط. تُشغّل من جذر المشروع، ولا تعيد تشغيل أدوات تكتب فوق أدلة 06-L4 التاريخية:

```sh
sha256sum content/06l2/tanzil-uthmani-1.1.txt content/06l2/quran-data.xml \

  content/06l2/numbering-profile.json
python3 - <<'PY'

records = []
for line_no, line in enumerate(text.splitlines(), 1):
    match = re.fullmatch(r'(\d+)\|(\d+)\|(.*)', line)
    if match:
        records.append((int(match[1]), int(match[2]), match[3], line_no))
keys = [(s, a) for s, a, _, _ in records]
assert len(keys) == len(set(keys)) == 6236
assert keys == sorted(keys) and keys[0] == (1, 1) and keys[-1] == (114, 6)

counts = collections.Counter(s for s, _, _, _ in records)
assert [counts[s] for s in range(1, 115)] == profile['expectedAyahsPerSurah']
expected_keys = [(s, a) for s, count in enumerate(profile['expectedAyahsPerSurah'], 1)
                 for a in range(1, count + 1)]
assert keys == expected_keys
index = json.loads((base / 'source-slice-index.json').read_text())

    value = u16[item['sourceStart'] * 2:item['sourceEnd'] * 2].decode('utf-16-le')
    assert (value, item['line']) == by_key[(item['surah'], item['ayah'])]
xml = ET.parse(base / 'quran-data.xml').getroot()
print(json.dumps({'surahs': len(counts), 'ayahs': len(records),
    'sourceSlicesMatched': len(index['records']),

PY
```
