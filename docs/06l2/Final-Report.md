# التسليم النهائي — MULAZAMA 06-L2

**القرار: ج. غير جاهز.** أُنجز النطاق الهندسي الآمن وأُصلحت عيوب أدوات التراجع، لكن اعتماد المحتوى والمنهج وتفعيل مسار الجدولة وربط الورد وإكمال الرحلتين والتشغيل والتجربة البشرية ما زالت معلقة. لا تصلح النسخة لتجربة تعلم قرآني فعلية أو إطلاق عام؛ يمكن مراجعتها هندسيًا محليًا مع استمرار الحجب.

بُنيت النسخة من حزمة ZIP للمرحلة 06-L1 وسجل Git bundle المطابق لها، في نسخة عمل آمنة على الفرع `release/06-l2`. فُحصت 782 بصمة من الأصل، وأُعيد تنفيذ اختبارات الأساس ونجحت 727/727. لم يُستخدم إصدار أقدم أساسًا ولم يُحذف تاريخ المشروع. [تدقيق الأصل](Audit-06L1.md)، [إيصال المصدر](evidence/source-receipt.json).

## المنفذ الفعلي

- جُلب نص Tanzil Uthmani 1.1 من ناشره مع حقوق استخدامه وبياناته الوصفية، وحُفظ محجورًا خارج التطبيق. شمل التدقيق UTF-8 والترتيب والتكرار والبصمات لـ114 سورة و6236 آية، ومطابقة DOM كاملة، ومعاينة بعرضي 320 و1440 بكسل، ولوحة المفاتيح، ورفض المصدر المختلف. تعذر جلب مصدر المجمع الرسمي بسبب الصيانة وTLS؛ لم تنفذ مقارنة مستقلة أو يُستكمل التوقيع أو اعتماد خط العرض. لم يُعدّل النص أو يُفعّل المحتوى.
- أضيفت أداة لقراءة أثر انتقال FSRS، تقارن كل وحدة وتحفظ وقائعها وبصمتها وخططها. ثبت التكامل المحدد بين HME والمرجع المستقل للدرجات والوقت والتصحيح والتكرار، وأُعيدت 40 حالة مطابقة للمسار المصحح. لم تتغير الخوارزمية أو المعاملات أو سلم التقييم أو القيم المتوقعة، ولم يُفعّل المسار للكتابة أو يُنفذ ترحيل على بيانات المستخدمين.
- نُفذت تمارين IndexedDB والنسخ والاستعادة والتراجع في قواعد QA منفصلة، واختبارات انحدار لتبويب قديم وبلاغ يتضمن وسومًا خبيثة. أعاد التدقيق الحي للاعتماديات صفر مشكلات معروفة؛ لم تُنفذ ترقيات عشوائية أو تُتجاهل تنبيهات.
- أُنشئت حزم معاينة مبصومة وخادم محلي مع CSP وقفل واختيار مشروط للإصدار. أُصلح قبول البيان الفارغ أو الناقص، وثُبتت البصمة التاريخية عند التراجع، مع تسعة اختبارات انحدار جديدة. اختُبر الانتقال L1→L2→L1 وحفظ الصفوف المشفرة والتفضيلات والحجب والعمل دون اتصال فعليًا، مع فحص HTTPS محلي منفصل. لم تُنشأ استضافة عامة.
- حُدث إعداد CI ومشغل التحقق المحلي وحزمة الأساس القابلة للنقل لاختبارات التراجع، ووُحد اختيار المتصفح بين التشغيل المحلي وCI. حُدث سجل الأعمال الذي يضم 18 بندًا بمعرفاته وتبعياته نفسها. لم يُنشأ مسار نشر آلي أو حسابات أو خدمات مدفوعة.

## قرار معايير القبول

| معيار الإطلاق | الحالة النهائية |
|---|---|
| اعتماد المحتوى القرآني | غير مستوفى: المصدر المساند المرشح محجور؛ المصدر الرسمي والمقارنة والكتالوج والمراجعة ما زالت معلقة. |
| اعتماد الجدولة والتكامل | المطابقة والتكامل المحددان ناجحان؛ تفعيل المسار والقياس واعتماد الإصدار لم تكتمل. |
| اكتمال رحلة الحفظ | محجوبة؛ اختُبر الإعداد المحلي فقط. |
| اكتمال رحلة المراجعة | محجوبة؛ التصريح بالمحفوظات ليس إثباتًا للإتقان. |
| البيانات والاستعادة | نجح نطاق QA؛ اعتماد الإصدار المرشح والترحيل واختبارات أجهزة الاستخدام المستهدفة غير مكتملة. |
| الورد الشخصي الفعلي | عقد النشاط والخطة والنتيجة غير معتمد، ولم يُنفذ ورد قرآني فعلي. |
| تقدم من بيانات حقيقية | نجح اشتقاق المؤشرات وتصحيحها على بيانات QA؛ لا مؤشرات مزيفة ولا تاريخ حافظ فعلي ضمن التحقق. |
| الأمن | لم يثبت مانع حرج في الفحوص المحددة؛ المراجعة المستقلة واعتماد بيئة التشغيل غير مكتملين. |
| العربية والإتاحة | نجحت الأتمتة؛ لم تُنفذ مراجعة بشرية بقارئ شاشة أو على الأجهزة المستهدفة. |
| الاستضافة والنطاق والدعم | الحسابات والملكية والبريد وقناة الدعم العامة غير مجهزة؛ أعاد DNS نتيجة NXDOMAIN وقت الفحص. |
| التجربة البشرية | لم تُنفذ؛ حُدد البروتوكول والمقاييس مسبقًا. |
| حل المشكلات الحرجة للتجربة | لم تبدأ التجربة؛ لا ادعاء بإغلاق مشكلاتها. |
| التحديث والتراجع | ثبت التمرين المحلي؛ تمرين مزود الاستضافة الفعلي وعقد الانتقال الحساس ما زالا معلقين. |
| موافقة الإطلاق | لم تصدر؛ لم يُنشر المشروع. |

اكتمل البندان L07 وL08 محليًا، وأُجل البند L18 بوصفه غير مانع. تبقى البنود الخمسة عشر الأخرى محجوبة تشغيليًا. فُصلت الأجزاء البرمجية والاختبارات المنفذة عن الاعتماد البشري والإجراء الخارجي. [سجل الإغلاق والمسؤول والدليل](Closure-Ledger.json)، [تقرير الموانع](Gate-Closure-Report.md).

## ما بقي والإجراء التالي

العمل التالي هو إغلاق البنود القائمة: توفير مصدر محدد ومقارنة وكتالوج واعتماد المنهج، ثم اعتماد تفعيل المسار المصحح وعقد انتقاله، وربط الورد والنتيجة وإثبات الرحلتين. يمكن حسم التشغيل والخصوصية والدعم بالتوازي. بعد ذلك يُعتمد الإصدار المرشح للتجربة، وتُنفذ تجربة مع 10–20 مشاركًا بموافقتهم، وتُحل مشكلاتها قبل قرار مستقل بالنشر. لا تتطلب هذه الخطوات فتح مرحلة مزايا جديدة.
