# التجربة البشرية المغلقة — بروتوكول 06-L2

**لم تُنفذ، ولم يُدعَ مشاركون، ولم تسجل موافقة أو شهادة مستخدم.** يبقى الإطلاق العام معلقًا عليها، ويظل بدء التجربة نفسها محجوبًا حتى اعتماد المحتوى والقياس والمسار المصحح والرحلتين والبيئة والخصوصية. خطة L1 محفوظة، وهذه إحالة تنفيذية بنفس المقاييس قبل الاطلاع على أي نتائج.

العينة10–20 بالغًا موافقًا، تشمل مبتدئين وأصحاب محفوظات ومسار الجمع. لا تضم قاصرين في البروتوكول الحالي. رموز المشاركين بدل أسمائهم في التحليل؛ لا تسجيل صوت/شاشة افتراضيًا، ولا جمع سجلات خام في CI. تعتمد هوية المشغلة وقناة الحقوق والغرض ومدة الاحتفاظ والانسحاب قبل الجمع. التجربة تقييم ملاءمة واستعمال أولي، وليست إثباتًا إحصائيًا للفاعلية التعليمية.

| المهمة | الهدف المسجل سلفًا |
|---|---|
| الإعداد بلا مساعدة | ≥90% مع عدد وزمن لكل فئة |
| أول ورد فعلي | ≥90% بلا تدخل؛ صفر تجاوز بوابة |
| نتيجة وتصحيح وحفظ وإعادة تحميل |100% سلامة أحداث؛ ≥90% يفهمون معنى النتيجة والتصريح |
| انقطاع واستئناف | صفر فقد أو جدولة غير مفسرة؛ ≥90% ينجزون المهمة |
| تقييم فائدة الورد1–5 | ≥80% بدرجة4أو5؛ لا يستبدل الاعتماد العلمي |
| عودة اختيارية7/14يومًا | ≥60%/50% مع المقام والمنسحبين والمفقودين، دون ضغط أو عقوبة |
| الخصوصية والإتاحة | صفر عائق حرج؛ هاتف ولوحة مفاتيح وقارئ شاشة بشري |

تسجل كل مهمة برمز الإصدار وبصمته والفئة والجهاز، وقت البداية/النهاية وعدد تفعيل الأوامر وتغيير القيم والمساعدات، نجاح/تعذر وسببه والعطل. لا تعد كل حرف تفاعلًا. يقاس فتح الموقع→بدء الورد وانتهاء التسميع→إقرار حفظ النتيجة فعليًا؛ القيم الحالية غير متاحة لأن الجلسة محجوبة، فلا تستبدل بهدف «نقرة واحدة» كأنها نتيجة.

توقف التجربة عند فقد بيانات أو عرض نص غير مطابق أو تسريب أو تجاوز اعتماد. يُحفظ الأصل وتُعزل النسخة، ويُصلح السبب ويعاد الاختبار المتأثر قبل الاستئناف. لا تغير الأهداف بأثر رجعي. بعد اليوم14 تصدر نتائج الأعداد الفعلية وحالات التعذر والانسحاب والحدود، ثم قرار منفصل. أي مشكلة حرجة تمنع الإطلاق مهما كانت المتوسطات.

النموذج التفصيلي والموافقة والمقاييس في [البروتوكول الموروث](../06l1/Closed-Trial-Plan.md). تعتمد L15 قبل الدعوة وL16 بعد النتائج وحل الحرج ثمL17 للموافقة؛ توثيق الخطة وحده لا يغلق أيًا منها.
