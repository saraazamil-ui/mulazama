## الأسرار وسلوك CI

فُحص كامل تاريخ التطبيق: 1245 blob، و44,238,870 بايت فريدة، ومحتويات خمسة أرشيفات متتبعة. لا أسرار مؤكدة أو ملفات بيئة/مفاتيح خاصة متتبعة. جميع التطابقات العامة العشرين كلمات مرور صناعية لاختبارات النسخ الاحتياطي؛ القيم محجوبة في [secrets-audit.json](secrets-audit.json). كما فُحصت blobs المستودع الرسمي العشرة ولم تظهر أسرار؛ ملفات SVG بلا scripts أو موارد خارجية.

حدود المسح: regex مخصص، لا gitleaks مثبت، لا تحقق شبكي لصلاحية الرموز، ولا فحص بصري لمحتوى الصور والخطوط الثنائية. لا يُعد ذلك اختبار اختراق أو تدقيقًا شاملًا للاعتماديات.

`main` الرسمي لا يحتوي workflows متتبعة. ملف QA المستورد يعمل على push وPR بصلاحية `contents: read` ويشغّل الفحوص ويحفظ أدلتها فقط؛ لا خطوة نشر. نتائج GitHub Actions منفصلة عن نجاح الاختبارات المحلية ويجب قراءتها من PR عند توفرها.

## توافق GitHub Actions بعد الاستيراد

نجح التثبيت النظيف `pnpm install --frozen-lockfile` على GitHub، لكن أول تشغيلين توقفا قبل الاختبارات لأن `ubuntu-latest` أصبح Ubuntu 26.04، وهو غير مدعوم بإصدار Playwright 1.56.1 المثبت. دليل المحاولة: [تشغيل PR الأول](https://github.com/saraazamil-ui/mulazama/actions/runs/42385340898). الأدلة التاريخية المرفوعة آليًا من ذلك التشغيل لا تثبت تنفيذ اختبارات جديدة.

أُضيف إصلاح مستقل لتثبيت `runs-on: ubuntu-24.04` المدعوم داخل نسخة Playwright المثبتة، مع توضيح السبب في تعليق. جُدد أيضًا ملف build-context.generated.ts لأن .github مشمول في بصمة المصدر. هذان هما الاستثناءان الوحيدان في ملفات تسليم L4 الـ1300 بعد commit الاستيراد: بقيت 1298 مطابقة حرفيًا، وبقي الأصل الكامل في `df34d70` و`76e4332`. لا تغيير في نسخة Playwright أو lockfile أو منطق التطبيق أو شروط الاختبارات. بصمة مصدر فرع المراجعة بعد هذا الإصلاح هي `9b280bfd669c21a84910d9a9203423469135e24cdb0a520c283634dbb8120f79`، وليست موافقة إطلاق. تبقى manifests أدلة للتسليم الأصلي عند `df34d70`، وليست بيانًا جديدًا للفرع المعدّل. راجع [tree-preservation.json](tree-preservation.json) للاستثناء المحدد.

بعد الإصلاح نجحت محليًا 57 حالة خاصة بالإصدار والبصمة، وTypeScript والبناء وعزل المواد الصناعية. بقيت البوابات العشر محجوبة بالسياق الجديد (exit 2). حُفظ البناء الجديد خارجيًا وأعيد dist المتتبع إلى نسخة التسليم التاريخية. تفاصيل محاولة pnpm المحلية ونجاح الأوامر المباشرة المكافئة في [ci-runner-validation.json](ci-runner-validation.json).
