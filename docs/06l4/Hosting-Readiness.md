# النطاق والاستضافة — 06-L4

**النطاق الرسمي https://mulazama.sa؛ ملكيته وحالة تسجيله وربطه لم تُثبت من لوحة المسجل.** أفادت المالكة بشرائه من dnet.sa، ثم أفادت بأن الموقع غير جاهز. هذه العبارة لا تعني Active أو Pending. الفحص العام في 7 نوفمبر 2026 أعاد NXDOMAIN لسجلات A/AAAA/NS/MX/TXT/SOA و www و DMARC، و WHOIS أعاد No Match؛ فشل HTTPS قبل TLS لتعذر تحليل الاسم. لا ينفي هذا حصول دفع أو طلب تسجيل. [الأوامر الخام](evidence/ops-network-observed.json).

المستودع الخاص `saraazamil-ui/mulazama` موجود وبصلاحية إدارة عبر الموصل؛ يحوي الهوية ونصوص التشغيل ولم يستورد شفرة هذه النسخة. المعاينة القائمة https://mulazama-preview-05a.sara-a-zamil.chatgpt.site تخص 05-A، وبيانات الوصول المتصلة تُظهر المالك فقط، دون زوار خارجيين. لم تُحدّث أو تُعلن معاينة L4. [إيصال منقح](evidence/connected-operations-receipt.json). أُعد [طلب مراجعة توثيقي مستقل](https://github.com/saraazamil-ui/mulazama/pull/1) يصحح النطاق في README ويبين قدم المعاينة؛ لم يُدمج ولم ينشر موقعًا. نقل تاريخ Git كاملًا لم يتم: فحص نقل Git الطرفي رفض لعدم توفر مصادقة، دون طلب كلمة مرور. الحزمة وسجلها المحليان قابلان للاستعادة.

جاهز محليًا: build ثابت، خادم loopback مقيد بالأصول، HTTPS اختباري، تحديث ذري وتراجع مثبت،404/503، CI تحقق بلا نشر، مصدر مُجزّأ يشمل إعدادات deployment. فُتحت معاينة L4 في Safari على http://127.0.0.1:4184/؛ ليست استضافة خارجية. [فصل البيئات](../../deployment/environments06l4.json)، [نموذج DNS غير قابل للاستيراد](../../deployment/dns-records06l4.example.json).

البنية React/Vite ثابتة ولا تحتاج خادمًا لبيانات التعلم حاليًا. يمكن استخدام استضافة ثابتة تدعم HTTPS ورؤوس الأمان ونشر إصدارات ثابتة ومصادقة معاينة. Cloudflare Pages خيار موثق ولم يُعتمد أو يُنشأ حساب له: معايناته عامة افتراضيًا، وتفعيل Access للمعاينات وحده لا يحمي pages.dev الأساسي أو النطاق المخصص؛ يلزم حماية كل منفذ وصول قبل رفع محتوى تجربة. [توثيق الوصول](https://developers.cloudflare.com/pages/configuration/preview-deployments/). ربط apex عبر Pages يحتاج zone و nameservers المعطاة من الحساب؛ لا نخمن IP أو نغير NS الحالية. [توثيق النطاق](https://developers.cloudflare.com/pages/configuration/custom-domains/).

في dnet: افتحي «منتجاتي» وتفاصيل mulazama.sa للتأكد من الاسم والحالة وإكمال متطلبات التسجيل إن كانت معلقة. المسجل يشرح اعتماد الطلب وإدارة DNS في [دليل النطاقات](https://dnet.sa/domains). بعدها يجهز المهندس سجلات المضيف المختار وخطة تغيير/تراجع للموافقة، ثم يتحقق من DNS و TLS وجميع الروابط. لا يلزم إرسال هوية أو كلمة مرور إلى المحادثة. [الإجراء المختصر](Owner-Actions.md).
