# منهج الحفظ والتسميع الذاتي — مراجعة 06-L4

**التقييم ذاتي V1؛ ليس تحققًا آليًا من التلاوة ولا شهادة إتقان.** لم تتغير قواعد HME أو P0 أو سلم التسميع في هذه المرحلة. أُتيح مسار الاختبار الصناعي فقط، وبقي اعتماد صلاحية المنهج القرآني على مستوى المنتج معلقًا.

| السلوك القائم | تفسيره وحدوده |
|---|---|
| قراءة المقطع والتكرار ثم إخفاؤه والتسميع | خطوات استرجاع ذاتي؛ عدد التكرارات ليس إثبات حفظ |
| «كاملًا بلا خطأ معلوم» بصعوبة/جهد عادي/بسهولة | تصريح صريح بالإكمال والخطأ والجهد؛ ينتقل إلى درجات 2/3/4 وفق العقد الموجود |
| خطأ معلوم أو تلميح أو كشف النص أو تعذر الاسترجاع | درجة 1 إذا كانت فرصة مؤهلة؛ لا يمحو اختيار «بسهولة» واقعة الكشف |
| توقف تقني/شخصي أو معلومة ناقصة | لا تُختلق نتيجة ناجحة؛ المحاولة المنقطعة تستلزم إعادة محاولة واضحة |
| التصحيح | واقعة تتبع الأصل، يعاد الحساب في وقت المحاولة الأصلية، ولا ينشئ تسميعًا جديدًا |
| إنجاز اليوم | إكمال نشاط صالح من الأحداث؛ فتحه أو إلغاؤه ليس إنجازًا |
| تغطية مواضع ذات نجاح مسجل | اتحاد معرفات دون تكرار، منفصل عن الإتقان وعن اكتمال معيار حفظ معتمد |
| مواضع تعثر | وصف ما بلّغ عنه المستخدم؛ لا حكم ضعف ثابت بعد خطأ عارض |
| ثبات الحفظ | لا نسبة شكلية؛ نقص الأدلة يبقى معلنًا ولا يساوي احتمال FSRS إتقانًا قرآنيًا |
| العودة بعد انقطاع | ترتيب أولويات محدود بوقت اليوم؛ لا يحذف تاريخ المتأخرات |

مراجعة الشفرة والاختبارات تثبت اتساق التنفيذ مع هذا العقد، لا صحته التربوية النهائية. أرقام P0 موسومة في الأصل بأنها فرضيات هندسية: التكرار والنجاحات والفواصل والحدود الذاتية وأولوية التعافي وسعة الخطة ليست ثوابت علمية مثبتة. يراجع المختص ملاءمة هذه الحدود ومعيار اكتمال الحفظ وتفسير المساعدة والخطأ والفاصل الزمني قبل اعتماد إصدار المنتج. لا حاجة إلى محرك تنبؤ آخر أو مدخل نسبة تقدم يدوي.

خطوات الواجهة الهندسية المعتادة لم تزد: ثلاث خطوات إعداد، نقرة من الرئيسية لبدء نشاط متاح، نقرة لوصف النتيجة المعتادة، ونقرتان للتصحيح. لا إضافة نموذج أو طلب عدد كلمات موجود في الوحدة. نجاح هذه المسارات آليًا لا يعوض تجربة حافظ فعلي.
