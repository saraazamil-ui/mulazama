# أمن البيانات والخصوصية — 06-L4

**لم يكشف التدقيق الحالي ثغرات اعتماديات معروفة؛ اعتماد أمن التشغيل والخصوصية ما زال مفتوحًا.** أعاد registry صفر تنبيهات لكل درجات الشدة في 212 اعتمادًا. لا تحديث أو ignore أو audit-fix؛ [النتيجة](evidence/dependency-audit.json) و[ربطها بالقفل](evidence/dependency-audit-binding.json). نجح فحص الأسرار المحدود وعزل مواد وصلاحيات الاختبار عن البناء العام، ولا يعني ذلك اختبار اختراق مستقلًا أو انعدام كل ثغرة.

بيانات التعلم محفوظة محليًا في IndexedDB مشفرة؛ مفتاح الجهاز داخل المتصفح نفسه. توجد نسخة محمولة مشفرة بكلمة مرور، ولا توجد مزامنة حساب أو تسجيل صوت أو إرسال تلقائي للنتائج أو SDK تحليلات. العامل الخدمي يخزن أصول الواجهة فقط. يثبت فحص المتصفح الحفظ والتصحيح والتكرار والفساد والتزامن والاستعادة وفشل الكتابة، ويثبت التحديث والتراجع مساواة الصفوف المشفرة قبل/بعد. لا ملفات حافظ حقيقية مستخدمة أو محذوفة، ولا ترحيل صامت. الحذف المتعمد وظيفة قائمة لم تُنفذ على بيانات المالكة.

التخزين المحلي ليس ضمان بقاء دائمًا أو حماية من شخص يستخدم المتصفح المفتوح/شفرة من الأصل نفسه. النسخ المصدرة لا تختفي عند حذف البيانات المحلية. اختلاف النطاق/البروتوكول/المنفذ ينشئ أصل تخزين مختلفًا؛ بيانات المعاينة لا تظهر تلقائيًا على mulazama.sa. يلزم تصدير/استعادة مخولان بعد اعتماد قارئ النسخة، لا نسخ قاعدة عشوائيًا أو مسح بيانات لمعالجة الأعطال.

الخادم المحلي يقدم CSP و nosniff و no-referrer ومنع camera/microphone/geolocation، ويرفض traversal وطرق الكتابة ويقدم أصولًا مثبتة فقط. اختبار TLS محلي بشهادة مؤقتة لا يعد إثبات HTTPS عام. صفحات 404 و 503 تحتفظ بالسجل، و 503 يحمل Retry-After؛ حالة الصيانة على الخادم لا تسحب نسخة offline محفوظة مسبقًا. لا تواقيع اعتماد مصطنعة، ولا فتح للجلسات عبر URL أو الاستعادة أو مدخل الاختبار.

مسودة الخصوصية تصف المعالجة الحالية، ووسيلة الدعم المقترحة غير مفعلة ولا تحمل mailto. عند اختيار المضيف/البريد يلزم تحديد هوية وصفة المشغلة ووسيلة ممارسة الحقوق وسجلات الاتصال ومددها والموردين ومكان المعالجة وحوادث التسرب والقاصرين وحساسية بيانات التعلم الديني. التسجيل المحلي لا يكفي لإعلان امتثال نهائي. يراجع المختص المتطلبات المناسبة وفق [نظام حماية البيانات ولوائحه وأدلته لدى سدايا](https://dgp.sdaia.gov.sa/wps/portal/pdp/knowledgecenter).

مراقبة التشغيل الحالية عدادات requests/failures محلية دون محتوى تسميع أو سجلات أحداث. التنبيه الخارجي ومسؤول الاستجابة والاحتفاظ بسجلات المضيف لم تُجهز؛ لا ادعاء إغلاقها بوثيقة. [قائمة الأعمال الموحدة](Closure-Ledger.json)، [الاختبارات](Test-Report.md).
