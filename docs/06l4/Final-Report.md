# تسليم 06-L4 — مُلازَمَة

**القرار النهائي: غير جاهز للتجربة القرآنية المغلقة أو الإطلاق العام.** نُفذت التعديلات الهندسية أدناه، وبقي اعتماد المحتوى والمنهج وسياق الإصدار، وتفعيل النطاق والاستضافة والبريد والتجربة البشرية. لم تستوفَ جميع شروط نجاح المرحلة. لم يُنشر الموقع أو تُغيّر DNS الحية أو تُفتح جلسة قرآنية.

بدأ العمل من ZIP وسجل Git للمرحلة 06-L3، بعد فحص CRC وبصمات 1166 ملفًا ومطابقة جميع ملفات الأرشيف البالغ عددها 1168 مع Git. أُنشئت نسخة استرجاع مستقلة قبل التعديل. [إيصال المصدر](evidence/source-receipt.json). الإصدار الحالي 0.6.0-alpha.4؛ لم يُستخدم أساس أقدم أو يُعد بناء المشروع.

أُصلح تحقق ترتيب مواضع الجلسة وحدودها دون تغيير النص. أُضيفت صفحات 404 و 503 مع فحص العمل دون اتصال، وثُبّت النطاق mulazama.sa والبريد المقترح بحالة غير مفعلة. أصبحت بصمة الإصدار تشمل إعدادات التشغيل. نُفذ تحديث L3→L4→L3، وأضيف اختبار رحلتي الكمبيوتر للمسار الصناعي. أُعد [طلب مراجعة توثيقي في المستودع](https://github.com/saraazamil-ui/mulazama/pull/1) دون دمج أو نشر. فُتحت المعاينة المحلية في Safari بطلب المالكة.

النتائج النهائية: **897 اختبارًا برمجيًا، و 35 اختبار واجهة عادية مع 12 رحلة هندسية، و 4+2 دون اتصال، و 3 للنشر والتراجع المحلي، و 5 لعرض محتوى محجور، و 40/40 مطابقة FSRS**. صفر فشل أو تجاوز في الجولة النهائية؛ محاولة Chrome المتعذرة محفوظة ولا تُحسب نجاحًا. [الاختبارات وحدودها](Test-Report.md). بقيت ثلاثة تدقيقات اعتماد محجوبة برمز 2 وجميع G01–G10 محجوبة.

بقيت **994 ملفًا أصليًا محميًا** دون تغيير، تشمل النص والنواة والأوزان و P0 وخدمات الأحداث والتخزين والمراجع والتقارير التاريخية. لم يُنفذ ترحيل أو تستخدم بيانات حافظ حقيقية في الاختبارات. [دليل الحماية](evidence/protected-files-check.json)، [الملفات المعدلة](Changed-Files.json)، [أمن البيانات](Data-Security-Report.md).

التسميع الذاتي لا يحتاج معلّمًا لكل جلسة، لكن حزمة المنتج لم تعتمد بعد. الفحص البنيوي للنص والمطابقة العددية لا يعوضان اعتماد المحتوى والمنهج. [المحتوى](Content-Approval-Report.md)، [المنهج](Self-Learning-Method.md)، [FSRS](FSRS-Integration-Report.md)، [رحلة الجديد](New-Hafiz-Journey.md)، [رحلة السابق](Prior-Hafiz-Journey.md).
