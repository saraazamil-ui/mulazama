# تجربة مغلقة لمدة 14 يومًا — لم تبدأ

لا تجنيد ولا بيانات أو شهادات أو نسب نجاح بشرية فعلية. تبدأ التجربة بعد اعتماد حزمة القرآن والمنهج والمحرك وسلامة البيانات والبيئة المقيدة وقناة دعم وخصوصية مناسبة، وموافقة المالكة على التجربة. لا تُعامل المعاينة الهندسية أو 05-A كبديل.

10–20 مشاركًا متطوعًا، يضم مبتدئين وأصحاب محفوظ سابق ومسارًا مختلطًا. تختار مسؤولة التجربة توزيعًا قبل البدء؛ لا نجمع اسمًا أو صوتًا أو سجلًا كاملًا لقياس الاستخدام. موافقة واضحة، حق الانسحاب، ومعرفات تجربة بدل الأسماء. توثيق أي بلاغ أو لقطة يتم باختيار المشارك وبأقل بيانات؛ قناة الدعم المختبرة شرط.

| المقياس المحدد مسبقًا | هدف قرار أولي |
|---|---|
| إكمال الإعداد دون تدخل |90% على الأقل من المحاولين |
| إكمال أول جلسة صحيحة وحفظها |85% على الأقل من المبتدئين للجلسة |
| بدء ورد متاح بعد الإعداد |وسيط نقرة واحدة من الرئيسية |
| العودة في اليوم 7 واليوم 14 |هدف 60% ثم 50%، مع عرض المقام والغياب دون إخفاء المنسحبين |
| فهم أن النتيجة ذاتية |كل مشارك يستطيع شرح الفرق في سؤال قصير |
| فقد بيانات/تجاوز بوابة/نص غير مطابق |صفر؛ أي حالة توقف التجربة للتحقيق |

قبل البدء: حفظ نسخة مشفرة واستعادة على جهاز اختبار، اعتماد الإصدار وبصمته، والتحقق من منع غير المدعوين على الصفحة والأصول والعامل الخدمي وجميع عناوين المضيف. اليوم 0: الإعداد وأول جلسة والتصحيح؛ اليوم 7: العودة وفائدة الورد والمشكلات؛ اليوم 14: الاستمرار وأسباب التوقف والاستعادة. لا إشعارات قسرية أو مقارنات اجتماعية أو عقوبة انقطاع.

تُسجل الأعطال بموافقة المشارك، مع تمييز خطأ منتج/عدم فهم/غياب بيانات، وتوثق إعادة الاختبار بعد الحل. لا إطلاق عام قبل إغلاق كل عطل حرج ومراجعة النتائج والخصوصية والتراجع ثم موافقة صريحة مرتبطة بالنسخة. هذه عينة قابلية استخدام وملاءمة أولية، وليست إثباتًا إحصائيًا عامًا لفاعلية تعليمية.
