# مُلازَمَة — تغييرات 06-D2

الأساس الوحيد هو06-D1، بعد التشخيص وتثبيت قرار النطاق الآمن في [إيصال ما قبل التعديل](evidence/pre-change-decision.json).

| التغيير | الغرض والأثر |
|---|---|
| HistoryApplication ووصله من main.tsx | يقرأ كامل سجل المنتج وHME المتحقق؛ لا ينشئ LearningApplication أو adapter أو تفويض تشغيل أو HME جديدًا بمجرد فتح التطبيق |
| واجهة مخزن المنتج المقيدة | تحفظ أحداث النطاقين عند الكتابة، وتمنع استبدالًا جزئيًا أو نسخة ناقصة أو تصادم commandId بين النطاقات |
| تحقق غلاف أحداث HME | يرفض الحقول الزائدة وهوية عملية لا تطابق الأمر؛ لا يغير الأوامر الصحيحة أو درجاتها أو إصداراتها |
| طابور refresh مع dispatch | يمنع التراجع إلى قراءة قديمة بعد كتابة مؤكدة؛ CAS يحمي التداخل مع الاستعادة والنوافذ الأخرى |
| حجب جمع coverage عبر الطبعات | لا يدمج مفتاحين متشابهين من طبعتين بلا خريطة؛ يبقى اتحاد التداخل داخل الطبعة كما هو |
| حقول التسميع والتصحيح | تحمل أحدث ملاحظة، تحافظ على المسودة عند الفشل/التعارض، وتمنع تصحيحًا مطابقًا بلا تغيير |
| اختيار النطاق الكامل | يملأ عدد الكلمات المطلوب المسجل بعد اختيار المستخدم الصريح؛ لا يخمن الأخطاء أو الجهد أو الفاصل |
| إشعار الحفظ وتحديث التقدم | يعرض انتظار الإيصال ثم النجاح، ويعيد القراءة بعد التأكيد دون إدخال نسبة أو نموذج إضافي |
| روابط الصفحة الرئيسية | تعطل إجراءات التعلم المحجوبة، وتبقي مراجعة الخطة والتقدم متاحتين؛ حاجز المسارات والأوامر باقٍ |
| مسبار FSRS مستقل واختبارات جديدة | يوسع المقارنة إلى32 حالة ويثبت التصحيح والاستعادة دون انتخاب المرشح |

نسخة الإسقاط `06-D2-observed-activity-1` تشير لتعريف القراءة في هذه الحزمة، وليست نسخة جديدة لخوارزمية أو مخطط أحداث. لم يتغير FSRS أو أوزانه أو HME P0 أو القرآن أو الحقوق أو بوابات05-C أو تخزين IndexedDB أو صيغة النسخة المشفرة أو المكتبات والقفل. تغير سياق البناء المولد ليطابق المصدر النهائي فقط.

الفهرس التفصيلي وبصمات الملفات قبل/بعد في [Changed-Files.json](Changed-Files.json)، مع البناء والتقارير المضافة. الملفات المصدرية المعدلة: main.tsx، App.tsx، LearningEngineScreen.tsx، application/service.ts، application/learning.ts، application/learning-ui-adapter.ts، progress/projection.ts، وسياق البناء المولد. ترد الملفات الجديدة في القائمة الآلية كاملة.

انخفض سيناريو التسميع الكامل المقاس6→5 تفاعلات دلالية، وتصحيح الأخطاء مع المحافظة على القيم7→3؛ راجع [القياس وحدوده](User-Steps-and-UX.md). لا ادعاء بتقييم علمي صحيح بنقرة واحدة دون ملاحظة، ولا جلسة إنتاج مفتوحة.

الاسترجاع: ZIP06-D1 الأصلي محفوظ دون تغيير، مع README06-D1 وتقارير05-A/B/C و06-D1 كما وردت. لا ترحيل جديد أو تعديل إصدارات وقائع. تقارير06-D2 تبين اختلاف مدخل06-D1 الذي لا يعرض التاريخ المختلط؛ الرجوع إلى واجهته ليس طريقة لإصلاح سجل مختلط أو حذف نصفه. حفظ النسخة المشفرة الكاملة يسبق أي استبدال فعلي مصرح به؛ لم تُجر استعادة إنتاجية في هذه المرحلة.
