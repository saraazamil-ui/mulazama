# مُلازَمَة — المرجع المستقل وحدود الثقة 06-E1

المرجع المقابل هو **ts-fsrs 5.4.2 / FSRS-6**، لا أحدث فرع main ولا ترقية إلى نموذج آخر. صفحة الإصدار الرسمية تربط v5.4.2 بالالتزام `bb71e35a2f5af5a5ac6cce9ef7c41ad24855721d`. المصادر: [الإصدار الرسمي](https://github.com/open-spaced-repetition/ts-fsrs/releases/tag/v5.4.2)، و[خوارزمية الالتزام المثبت](https://github.com/open-spaced-repetition/ts-fsrs/blob/bb71e35a2f5af5a5ac6cce9ef7c41ad24855721d/packages/fsrs/src/algorithm.ts).

## ما نُفذ

1. فُحص ZIP المرحلة06-D2 وبصماته قبل التعديل، ثم فُحص المرجع المعبأ: الاسم والإصدار والترخيص، وفك USTAR بحدود وحماية للمسارات، وSRI SHA-512، ومقارنة جميع الملفات13 ببايتات tarball وإيصال SHA-256. لم يقتصر الفحص على package.json.
2. حُمّل ملف ESM الأصلي ونُفذت دوال المكتبة مباشرة. لا يعاد بناء «مرجع» من معادلات مُلازَمَة، ولا يؤخذ expected من مرشح round8.
3. جُلبت عبر HTTPS بيانات npm للإصدار5.4.2 والحزمة ومفاتيح السجل، ومصدر algorithm.ts من الالتزام المثبت وبيانات الالتزام والإصدار من GitHub. أعادت الطلبات200، وسُجلت بايتاتها وبصماتها في [إيصالات الجلب](evidence/online-reference/fetch-receipt.json).
4. تحقق `scripts/verify-fsrs-reference-06e1.mjs` محليًا من توقيع سجل npm باستخدام ECDSA-P256-SHA256 والمفتاح المجلب من نقطة npm الرسمية. طابقت الحزمة الجديدة البايتات المثبتة، وطابق مصدر algorithm.ts داخل source map المصدر الرسمي عند الالتزام نفسه. سجل GitHub API أن توقيع الالتزام صحيح؛ هذا ليس تنفيذ تحقق GPG محلي. [دليل التحقق النهائي](evidence/reference-verification.json).

مصدر npm المثبت: [بيانات الإصدار](https://registry.npmjs.org/ts-fsrs/5.4.2)، و[حزمة5.4.2](https://registry.npmjs.org/ts-fsrs/-/ts-fsrs-5.4.2.tgz). SRI:

ترخيص MIT محفوظ. المرجع بلا تبعيات transitive في package.json؛ ينفذ المسبار ملف ESM المتحقق فقط. دليل فحص البايتات يسجل `executed:false` لأنه لا يدعي تشغيل الخوارزمية؛ دليل التحقيق العددي المنفصل يسجل `executed:true` بعد استدعاء upstream فعليًا. لا تناقض بين النطاقين.

## صلاحية حالات المقارنة

الحالات32 موروثة من06-D2 بوصفها **مدخلات فقط**، لا مخرجات ذهبية أُنشئت من المشروع. يثبت الاختبار E1-C42 بصمات ملفات الحالات والمقارن الأصلي مقابل manifest06-D2. لم تتغير السماحية المطلقة والنسبية1e-12. تغطي المجموعة12 فرعًا مطلوبًا، وأضيفت8 حواف موثقة في المصفوفة.

الدوال المنتجة للمتوقع هي `next_state` و`forgetting_curve` و`next_interval` على نفس ذاكرة البداية والدرجة والتاريخ وretention. تُقارن S وD وR واليوم الصحيح والفاصل وتاريخ الاستحقاق، ويعاد التنفيذ لاختبار الحتمية. لا تسمى هذه النتائج اعتمادًا لمعيار التسميع أو حفظ القرآن.

## إعدادات المقارنة

| model | FSRS-6 |
| weights | نفس21 قيمة بالمشروع، تطابق default_w حرفيًا |

| enable_short_term |true |
| enable_fuzz |false |
| learning_steps / relearning_steps |[] في مسبار النواة |
| الزمن |floor(فرق الملي ثانية/86400000)، بلحظات مطلقة |

قوائم steps الفارغة تحدد نطاق النواة؛ لا يعني ذلك أن BasicScheduler الكامل مطابق أو أن المشروع يتبع كل قواعده للانتقال بين learning/relearning أو لترتيب الفواصل بين الدرجات. لا تُقارن سياسة HME التربوية بقرارات مكتبة البطاقات لمجرد وجود FSRS داخلهما.

## حدود الثقة

ثبت توقيع سجل npm محليًا، لكن الثقة في مفتاحه تستند إلى نقطة HTTPS الرسمية التي جُلب منها. لم تُتحقق تشفيريًا سلسلة Sigstore وشهادتها وسجل الشفافية؛ بقي العلم الخاص بها false. حالة توقيع الالتزام من GitHub دليل من خدمته، لا تدقيقًا محليًا مستقلًا لكل التوقيعات. لم يُنشأ اعتماد إنتاج أو توقيع بوابة أو انتخاب ترحيل.

نجاح40 حالة بالمحرك المصحح يثبت المطابقة ضمن العقد والحالات المقاسة. لا ينتخب خوارزمية للبيانات القديمة، ولا يثبت النموذج علميًا للقرآن، ولا يغلق بوابات المحتوى والتقييم والتجربة.
