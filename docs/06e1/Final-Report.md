رُوجعت الأدلة، وأعيد تشغيل596 اختبارًا والأنواع على الأصل المستخرج قبل التعديل. كُتبت [خطة التغيير والترحيل](Change-and-Migration-Plan.md) قبل تنفيذ الحساب المصحح: الوقائع والخطط القديمة مرتبطة بهويةbinary64، وتغييرها مباشرة قد يغير تفسير التاريخ. لذلك ظل المفسر التاريخي كما هو، وأصبح الحساب المصحح مسارًا صريحًا يبدأ من الملاحظات الأصلية وآخر تصحيحاتها، دون كتابة أو استبدال.

## سبب الفشل وما عولج

عدم المطابقة30/32 سببه المثبت إغفال التقريب المرحلي إلى8 خانات في عقد ts-fsrs5.4.2. لم يثبت اختلاف نموذج أو أوزان أو ترتيب أو حساب يوم في الحالات الأصلية. أثبتت تجربة سببية أن تعطيل التقريب في نسخة تشخيصية منفصلة من upstream يجعلها تطابق القديم32/32، بينما بقي المرجع المقبول الأصلي دون تغيير.

أضيفت8 حواف؛ ثلاث منها تغير الفاصل يومًا كاملًا. كشفت إحداها أثر ترتيب العمليات قرب نصف اليوم بالإضافة إلى التقريب. كل الحالات40 مفسرة. استُخدمت نواةround8 الموجودة خلف محول كامل التحقق وبنفس شكل الواجهة، وأضيف مسار دمج HME يعيد حساب السلسلة منnull، ويمنع تكرار الفرصة والعنقود ويحفظ أثر التصحيحات ووقت التسميع الأصلي. لم تتغير الأوزان أو قواعد التقييم أو صلاحيات البوابات.

جُلب المرجع الرسمي مجددًا، وطابقت بايتاته الحزمة المثبتة، وتحقق توقيع سجل npm محليًا، وطابق source map مصدر الالتزام. حدود GitHub وSigstore موثقة؛ لا اعتماد إنتاج أو علمي مستنتج من هذه الفحوص.

أُضيف إسقاط لكل وحدة وطبعة ونسخة قياس: تسجيل الوحدة، جميع محاولات الاسترجاع، الملاحظات الحالية وسلسلة التصحيح، مصادر التعرض والأخطاء، الفواصل المطلقة، وبيانات كفاية وصفية. يبقى تاريخ الحفظ الموثق غير متاح حيث لا توجد واقعة اكتساب معتمدة. لا توقعات إتقان أو استحقاقات أو نسب ثبات في هذا الملف، ولا تخزين مشتق أو نموذج بديل لـFSRS.

## نتائج التسليم وحدوده

**680/680 برمجيًا،27/27 متصفح،3/3 دون اتصال**؛ صفر فشل أو تجاوز في التشغيل النهائي. ضمنها فحوص IndexedDB والتصحيح والاستعادة والتوقيت والبوابات وRTL وعرض الهاتف والإتاحة الآلية. TypeScript والبناء والتحقق الرسمي نجحت. حُفظت إخفاقات التطوير وعيب مصفوفة المعاملات الذي كشفه التدقيق وإصلاحه واختبار انحداره.

النواة المصححة تطابق32 الأصلية و8 الجديدة. المفسر التاريخي ما زال2/32 مقابل المرجع، محفوظًا لإعادة إنتاج الماضي؛ لا يقال إنه أصبح مطابقًا. المطابقة تخص نواة الذاكرة والفاصل الخام، لا كل BasicScheduler أو سياسةHME أو صلاحية المنهج للقرآن.

لم يتغير النص القرآني أو P0 أو الأوزان أو إصدارات الأحداث أو تخزين IndexedDB أو النسخ. أثبت فحص456 ملفًا موروثًا محميًا مطابقتها للأصل. كل G01–G10 محجوبة؛ لا نشر إنتاج أو ترحيل فعلي أو اختبار بشري لقارئ شاشة. المرحلة التالية محددة للانتخاب والانتقال القابل للاستعادة، وليست تفعيلًا تلقائيًا.
