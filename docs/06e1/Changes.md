# مُلازَمَة — التغييرات 06-E1

| التغيير | أثره |
|---|---|
| ReferenceFsrsAdapter | واجهة مماثلة للمحول القديم تستعمل عقد round8 المثبت؛ تحقق صارم للوقت والحالة والأوزان والهوية؛ لا تمرير حالةbinary64 جاهزة إلى المصحح |
| rebuildAdaptiveSchedule | يعيد الحساب منnull لكل وحدة، بعد التحقق من السجل وتطبيق أحدث التصحيحات والأهلية ومنع تكرار الفرصة والعنقود؛ يخرج مقارنة هندسية لا خطة تنفيذ |
| projectPersonalMemory | ملف مشتق لكل وحدة/طبعة/نسخة قياس، مع جميع المحاولات ومصادرها وتاريخ التصحيح والتعرض والفواصل والبيانات الناقصة؛ لا يساوي التسجيل بتاريخ حفظ موثق |
| HistoryApplication | قراءتان منظمتان داخل طابور المالك تستدعيان الإسقاطين دون كتابة أو مخزن مشتق جديد |
| أدوات التحقيق والتحقق الرسمي | مقارنة40 حالة، تجارب سببية منفصلة، مصفوفة كاملة، تحقق توقيع npm ومطابقة التنزيل الرسمي مع المرجع المعبأ |
| الاختبارات |84 اختبارًا برمجيًا جديدًا،2متصفح،1offline؛ تفاصيل النتيجة في التقرير |
| واجهة التطبيق | تحديث تسمية المرحلة فقط إلى06-E1؛ تصميم06-D2 وحجب المؤشرات غير المعتمدة محفوظان |

نواةround8 كانت مرشحًا موجودًا في06-D2؛ أعيد استخدامها بدل استبدال FSRS عشوائيًا أو إدخال مكتبة جديدة إلى المنتج. أُضيف إليها محول كامل التحقق ومسار دمج فعلي للقراءة الهندسية، بعد إثبات سبب الاختلاف ومراجعة أثر إعادة الحساب. هوية الحساب `hme-fsrs6-ts542-round8-0.1.0` منفصلة عن الهوية التاريخية؛ الأوزان الـ21 وretention الافتراضي0.9 دون تغيير.

لم يتغير `src/core/fsrs.ts` أو `fsrs-rounded.ts` أو HME/P0 أو تحويل الملاحظة إلى درجة أو `VERSIONS/LEARNING_VERSIONS` أو `replayLearning` أو التخزين والنسخ أو النص القرآني والبوابات. لذلك لم يغيّر هذا التسليم نتائج تفسير الوقائع القديمة أو يرقّها صامتًا. إصلاح الحساب مثبت في المحول والمسار الجديدين؛ لا يُنسب إلى مفسر التوافق القديم.

الملفات الموجودة المعدلة هي `src/App.tsx` و`src/application/history-application.ts` وسياق البناء المولد، مع README وملفات التسليم والبناء. توجد ملفات مصدر واختبار وتقارير جديدة؛ [القائمة الآلية وبصمات قبل/بعد](Changed-Files.json) هي المرجع الكامل.

حُفظت نسخة06-D2 الأصلية وبصمتها وREADME التاريخي، ولم يضف المشروع تبعيات أو ترحيلًا أو حذفًا. تقارير المراحل السابقة مطابقة للأصل بعد نقل المخرجات التي أعادت اختبارات موروثة كتابتها إلى أدلة06-E1. فحص456 ملفًا موروثًا محميًا يؤكد ذلك.
