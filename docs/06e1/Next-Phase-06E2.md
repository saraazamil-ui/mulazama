# مُلازَمَة — توصية06-E2

**النطاق المقترح: انتخاب إصدار الجدولة وخطة انتقال الذاكرة بصورة قابلة للاستعادة، دون فتح بوابات المحتوى تلقائيًا.** أصل التحقيق والإصلاح العددي جاهز للمراجعة، لكن مسار الكتابة التاريخي لا ينتقل إلى المصحح بمجرد نجاحه40/40.

1. راجع تقرير المرجع والأسباب ومصفوفة40 حالة واعتمد عقد النواة المقصود: FSRS-6 وts-fsrs5.4.2 والأوزان المثبتة وround8 والزمن وretention. حدد إن كانت بوابةG02 تتطلب اكتمال تحقق Sigstore أو أدلة إضافية؛ لا تستبدل ذلك بادعاء توقيع لم ينفذ.
2. صمم انتخابًا صريحًا للكتابة الجديدة، يفصل نسخة أحداث المنتج عن نسخة تفسير التعلم. احتفظ بمفسر الوقائع القديمة وبهوية الحساب المصحح، ولا تعدل `FSRS_PROVENANCE` العام بطريقة تغير قبول كل التاريخ. راجع توقيع البوابات وربطها بالإصدار الجديد وبصمة المصدر.
3. استخدم إعادة البناء الحالية لإنتاج تقرير أثر لكل وحدة قبل أي تبديل: تسلسل المدخلات، استبعاد الأدلة، تغيرS/D والفاصل، ثم أثر سياسةHME والخطة بعد اعتمادها. لا تغير grade لتقليل الفرق، ولا تعيد تسمية حالة قديمة دون إعادة حساب من أصلها.
4. صمم الترحيل كإسقاط جديد منفصل مع نسخة مشفرة كاملة وبصمة الخام وإيصال CAS وخطة رجوع، ثم اختبر تعطل منتصفه والاستئناف وإعادة الفتح والاستعادة والتزامن. يجب حسم الخطط القديمة ذات مراجع الموعد، والسجلات غير الكافية أو مجهولة النسخة، قبل تبديل أي قراءة تنفيذية.
5. راجع مصدر كل عنصر في الذاكرة الشخصية مع مختصي التعليم والقياس. اعتماد تاريخ حفظ أو إتقان يتطلب معيار اكتساب وكتالوجًا وأدلة مناسبة؛ البيانات الوصفية الحالية ليست مؤشر ثبات علمي. لا تخصص معاملات المستخدم من عينات قليلة بلا سياسة تحقق مستقلة.
6. أغلق موانع النص والكتالوج وحقوقه وعقد نشاط اليوم وتقييم التسميع وبقية بوابات05-C بأدلتها. بعد ذلك فقط اختبر رحلة staging موجبة مع إتاحة بشرية، واطلب اعتماد النشر للإنتاج صراحة.

مخرجات06-E2 المتوقعة: قرار إصدار قابل للتدقيق، مصفوفة أثر انتقال، آلية ذرية قابلة للرجوع، اختبارات حفظ التاريخ والفشل والاستعادة، وتقرير بوابات محدث. لا حاجة إلى إعادة بناء المشروع أو محرك تنبؤ بديل أو رسوم ثبات شكلية.
