# سجل القرارات والبوابات المفتوحة

تاريخ الحالة: 5 نوفمبر 2026. المرجع PRD §17.5 و§23 و§25، وHME §27. «حسم تصميمي» يثبت العرض أو النطاق في النموذج فقط؛ لا يغلق سؤالًا علميًا أو قبول إنتاج.

التصنيفات الخمسة المطلوبة: (1) يمكن حسمه تصميميًا الآن؛ (2) يحتاج اختبار استخدام؛ (3) يحتاج تحققًا علميًا؛ (4) يحتاج مصدرًا قرآنيًا معتمدًا؛ (5) يخص البرمجة اللاحقة. قد يحمل القرار أكثر من تصنيف لأن العرض قابل للحسم بينما الدليل أو التنفيذ ما زال مفتوحًا.

## قرارات تسليم 04-B الإضافية

هذه قرارات تنفيذ نموذج، لا تعديلات على HME أو إعادة ترقيم لسجل D.

| ID محلي | القرار | السبب والحد |
|---|---|---|
| 04B-P01 | React/TypeScript محلي مستقل | يسلم نموذجًا قابلًا للفحص والتشغيل؛ ليس بناء iOS/Android نهائيًا |
| 04B-P02 | بيانات متصفح تجريبية بإصدار | تعاد بعد التحميل إن أقر التخزين؛ غير مشفرة وقابلة للمحو من المتصفح، ولا تستبدل قاعدة أحداث الإنتاج |
| 04B-P03 | نطاقات سورة/جزء/صفحة/آيات كتوصيف إدخال | لا تحويل مختلق بين الصفحات والأجزاء والسور؛ الاتحاد الكلي بالكلمات يبقى غير متاح حتى حزمة C01 |
| 04B-P04 | فصل محاكاة التفاعل عن التعلم الفعلي | لا حزمة قرآن معتمدة في التسليم؛ لا ينتج النموذج دليل تعلم أو نتيجة إتقان أو تفسيرًا مؤهلًا |
| 04B-P05 | شاشات الامتناع والتعذر مخرجات مقصودة | فقد النص/الصوت/التوقع/المحرك لا يملأ بنتيجة مصطنعة؛ لكل فعل رد واضح |
| 04B-P06 | سجل مرحلة 04 غير قابل للفحص | لم تتوفر مخرجات النموذج الأصلي وراء مراجع المحادثة؛ لا ندعي مقارنة بصرية أو إصلاح عيوب شاهدناها |

## ما لا يُحسم هنا

أعداد نجاح P0، فواصل المراجعة، سقوف التعاهد، عتبات التعب والعلاج، أوزان FSRS، معايرة التوقع، صحة النص والوقف، وتقييم التجويد. لا يغلق نجاح اختبارات React أيًا منها.
