## 1. الأصل وما أُعيد التحقق منه

قُرئت حزمة 05-A الحالية ومرجعا HME وPRD. تعذر إعادة تنزيل الملف الحالي بسبب DNS؛ استُخدمت نسخة الرفع المحلية المطابقة، مع مطابقة 133 ملفًا لبيان التسليم. تأكد أيضًا تطابق نصي المرجعين الحاليين مع النسختين المحليتين، عدا LF ختامي، وفق current-reference-comparison.json. بصمة ZIP الأصلية `9fac93cd0cf6e1ed260a04289361aad0c747288944d5189a762dc0c48cf0c41d`، والتفاصيل في `input-provenance.json`.

أُعيد تشغيل المصدر القديم في نسخة معزولة: **299/299** اختبارًا، TypeScript والبناء وفحص ملفات البناء ناجحة؛ بناء dist القديم مطابق بايتًا للأرشيف. فحص أمني محدود: 27 ملفًا بلا نتائج. محاولة pnpm المجمدة والتدقيق الشبكي فشلتا بسبب DNS لسجل الحزم. نتائج 21 تحققًا مستقلاً السابقة باقية شواهد تاريخية ولم تُعَد؛ لا تُحتسب في نتيجة هذه المرحلة. تقرير `Baseline-Audit.md` يحفظ الأوامر والإصدارات والسجلات.

## 2. المعمارية المستمرة

احتُفظ بواجهة React/TypeScript العربية وطبقات HME المستقلة؛ لم ينشأ مشروع بديل. نواة TypeScript مصدر واحد للحساب والسياسة، مع منافذ تخزين ومنصة. المسار العملي الحالي **Web فقط كبناء هندسي**. إعادة استعمال المحرك في تطبيق هاتف مستقبلي لا تعني وجود تطبيق أصلي الآن. لا مشاريع iOS/Android أو SDK مكتمل أو تشغيل محاكي في هذا التسليم.

النسخ: Node 24.22.1، TypeScript 5.9.3، React 19.2.0، Vite 7.1.12، Vitest 3.2.4، Playwright 1.56.1، مدير الحزم المحدد pnpm 11.25.0. لم تتغير الاعتماديات المباشرة؛ فُحصت بيانات تراخيص 171 حزمة مثبتة. نجاح تثبيت نظيف غير مثبت. أمر npm غير موجود في البيئة، فنُفذت سلسلة بناء package.json نفسها باستخدام Node والملفات المثبتة مباشرة؛ نجحت.

## 3. التنفيذ والإصلاحات الفعلية

- تحقق صريح من JSON والأغلفة والتوقيت والإصدارات ومصدر التقييم والتغطية قبل إعادة التشغيل أو النسخ؛ رفض الوصوليات والحقول المخفية والأنواع التي كانت تفقد معناها أثناء canonical.
- منع احتساب أمر خام مكرر بحدث جديد، ومنع تزوير مصدر تقييم أو فرصة اختبار أو عنقود دليل. التصحيح لا يتحول إلى مراجعة إضافية. التلميح محفوظ ويؤثر في الحكم.
- حفظ عدم يقين الانقطاع، بما فيه محاولة جديدة مستوردة عند refresh؛ لا يُسجل إتمام تسميع لم يكتمل.
- فحص مواعيد النموذج والسياسة والأصل والتخطيط، وربط مرشحي الخطة بحالة الوحدة. اختبارات 30/60/120 دقيقة والتعافي 3 أيام/3 أسابيع/3 أشهر موجودة وناجحة في النطاق الصناعي.
- ترحيل قاعدة البيانات إلى v3 وفهرس `utf16-v1` حتمي. تُفحص الأحداث المشفرة قبل إعادة فهرسة العمليات؛ الحالات القديمة الملتبسة تُحجب للمراجعة دون مسح أو ترحيل صامت.
- تحسين مخطط AES-GCM للنسخ ورفض ملفات ذات حقول غير مصادق عليها أو UTF غير سليم، وفحص إعادة التشغيل قبل الاستبدال الذري.
- أدوات حجر وتدقيق المحتوى وبيانات المراجعة، وأداة مطابقة FSRS مرجعية ثابتة البايتات، وبوابات إصدار موقعة ومربوطة بالمصدر والإصدارات والمحتوى والمنصة والبيئة.

أثبتت اختبارات المنتج قبل الإصلاح 24 فشلًا من 28 حالة. بعد الإصلاح نجح الانحدار المتصل **115/115**، بما فيه إعادة فتح ونسخ وإعادة ضبط 05-A. لا يعني ذلك أن معيار قبول إنتاجي كامل أصبح متحققًا. سجل الأسباب والملفات والاختبارات في `Defects-and-Fixes.md` و`Product-Replay-Integrity-Report.md`.

## 6. FSRS وHME

النواة الحالية FSRS-6 بحثية binary64 بأوزان موثقة وسياسة وقت وإصدار محفوظين. المرجع المرشح `ts-fsrs@5.4.2` والالتزام `bb71e35a2f5af5a5ac6cce9ef7c41ad24855721d`؛ لم تثبت بايتاته أو تنفذ متجهاته المستقلة، فلا تُنسب مطابقة حسابية إلى هذه المرحلة. أداة المطابقة لا تولد expected من مرشحنا. تبقى G02 مغلقة.

منطق HME مفصول عن FSRS. إصدار دليل التطبيق الجديد `hme-application-evidence-05b.1` يمنع إعادة تفسير سجل التعلم القديم بصمت؛ يحتاج القديم ترحيلًا صريحًا مع مقارنة ظل. لا يغير ذلك ملف إعدادات المنتج 05-A الصحيح. جدولة FSRS الدائمة لغير chunk محجوبة حتى اعتماد profile مناسب، مع الاحتفاظ بالملاحظة وتفسير الحجب. لا يعتمد الإتقان على التكرارات أو متوسط المقاطع أو احتمال النموذج. تظل ملفات القياس والكلفة والمراجعة العلمية وربط التعلم بالواجهة إنتاجيًا غير مكتملة.

## 7. التخزين والنسخ والواجهات

التخزين المستهدف IndexedDB بمعاملات ومراجعات CAS وتشفير AES-256-GCM ومفتاح Web Crypto غير قابل للاستخراج محفوظ في IDB. الفحوص الحالية تثبت المخزن المرجعي والتحقق والخوارزميات الخالصة فقط؛ إغلاق المتصفح والطاقة والترحيل والأداء الفعلي لا تزال غير متحققة.

النسخ: AES-256-GCM، PBKDF2-SHA256 بعدد 600000 دورة، salt 16 بايت وIV 12 بايت، مصادقة الرأس، كلمة استعادة بعدد نقاط Unicode وحدود بايتات موثقة، تحقق نسخة وإعادة تشغيل، واستبدال كامل بعد تأكيد مع CAS. اختبارات الكلمة الخاطئة والتعديل والنقص والتكرار وفشل الاستبدال ناجحة على Node/المخزن المرجعي. ليست شهادة إنتاجية لحفظ الملفات أو الاستعادة داخل المتصفح.

شاشات S01–S19 محفوظة. إعداد الخطة والتفضيلات وميزانية اليوم والتصريح بالنطاقات والبيانات متصلة بسجل المنتج الحقيقي؛ النطاق المعلن ليس حفظًا مختبرًا، ولا تتحول الفجوات إلى محفوظ. واجهة التعلم لا تزال محجوبة، وخدمة HME الصناعية لم تصبح جسرًا إنتاجيًا كاملًا للشاشات. لا تُعرض وقائع وهمية بوصفها حفظ المستخدم. التوقع يعرض صراحة نقص البيانات. الصوت والإشعارات الأصلية غير مفعلة.

## 8. المنصة والإتاحة والأداء والأمن

الويب بُني وفُحصت أصوله، دون تشغيل متصفح فعلي. iOS وAndroid غير منفذين وغير مختبرين. فحوص المكونات وRTL ناجحة ضمن المجموعة، لكن لا اختبارات قارئ شاشة أو عرض مصحف معتمد أو axe منفذة. تقارير المنصات والإتاحة تميز المكتوب عن المشغل.

قياس صناعي واحد على macOS/arm64 وNode: خطة 1000 مرشح نحو 0.79 ms، دفعة 10000 حدث في مخزن الذاكرة نحو 860.23 ms، تحميلها نحو 41.93 ms، وإعادة تشغيل 100 أمر منتج نحو 14.17 ms. هذه قياسات عملية الاختبار، وليست زمن بدء التطبيق أو أداء قاعدة جهاز أو P95 أو ضمان استخدام لسنوات. تفاصيلها في `Performance-Report.md`.

لا رفع تلقائي للبيانات أو التسجيلات، ولا إذن ميكروفون مطلوب. حماية المفتاح في المتصفح لا تحمي من XSS أو جلسة مفتوحة أو برمجية جهاز خبيثة. لم يُثبت محو جنائي لوسيط التخزين. الفحص النصي المحدود لا يثبت غياب كل الأسرار أو الثغرات. تقرير الأمن يتضمن نموذج التهديد والقيود.

## 9. ما يلزم قبل تجربة بشرية أو إطلاق

1. تنزيل محتوى طبعة واحدة ببياناتها وحقوقها وخطها، إثبات البصمات والمقارنة المستقلة، ثم توقيع متخصص مخول؛ لا يحل وكيل البرمجة محل هذا الاعتماد.
2. استرجاع مرجع FSRS الثابت مع أدلة مصدره، تشغيل المتجهات المستقلة ومعالجة الفروق العددية قبل أي تحديث إصدار أو ترحيل تاريخي.
3. تشغيل E2E وIndexedDB والاستعادة والترحيل والتزامن وoffline على بيئة تسمح بالمتصفح والخادم؛ إصلاح أي إخفاق قبل اعتماد بيانات بشرية.
4. استكمال جسر الواجهة وخدمة التعلم وتوليد الوحدات والكلفة والتشخيص والربط من محتوى معتمد، وإغلاق معايير العقود المبينة في المصفوفة.
5. مراجعة إتاحة وأمن وتراخيص وبروتوكول تجربة وموافقة مشاركين، وتعيين جهات التوقيع. بناء الهاتف واختباره عمل مستقل عند إنشاء مشروعه.
