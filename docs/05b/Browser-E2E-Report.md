## تحديث توقع BWEB10 بعد بوابات 05-B

أصبح `ApplicationService.perform()` يستدعي صلاحية الإصدار قبل تنفيذ أي أمر جلسة أو محاولة؛ لذلك رمز الرفض عند غياب الأدلة الموقعة هو `RELEASE_GATES_BLOCKED`. حُدّث توقع BWEB10 من رمز المحتوى القديم `CONTENT_UNAVAILABLE` إلى رمز البوابة المحدد، مع الإبقاء على رفض الأوامر الاثني عشر والتحقق من ثبات revision وعدد الأحداث وخلو الجلسات والمحاولات. أضيف أيضًا تحقق من مطابقة الأحداث الخام قبل الأوامر وبعدها حرفيًا؛ لم تُرخّص عملية تعلم أو يُحذف فحص حماية.

بعد هذا التعديل نجح `playwright test --list` واكتشف الحالات الخمس عشرة، ونجح فحص syntax محلي وحل imports الثابتة والتحقق من وجود واجهات ApplicationService وIndexedDbEventStore العامة المستعملة. هذا فحص مصدر واكتشاف اختبارات، وليس تشغيل أجسام اختبارات المتصفح. بقي المنفذ فعليًا صفرًا، وفق مانع EPERM السابق. الأدلة الجديدة: `post-gate-change-discovery.log` و`post-gate-change-public-api.json` و`post-gate-change-source-check.json`؛ الأخير يسجل بصمات المصدر بعد التعديل، ولا يستبدل بصمات المحاولة القديمة.
