# مُلازَمَة — MULAZAMA · Phase 06-D1

**تنفيذ جزئي آمن؛ غير جاهز للإنتاج.** حسّنت هذه الحزمة الصفحة الرئيسية وصفحة «تقدمي» وقراءة مؤشرات النشاط من الأحداث. تظل نسبة الحفظ ونسبة الورد والاستحقاقات الخوارزمية والثبات غير متاحة لغياب اعتماد مصادرها. جلسات القرآن محجوبة ببوابات 05-C.

ابدأ من [تقرير التسليم](docs/06d1/Final-Report.md)، ثم [الاختبارات الفعلية](docs/06d1/Test-Report.md)، و[الموانع](docs/06d1/Blockers.md)، و[تعريف المؤشرات](docs/06d1/Metric-Definitions.md).

## التشغيل

Node 24+ وpnpm 11.25.0، بنفس إصدارات الحزمة والقفل السابقة. لا يتضمن ZIP مجلد node_modules. لم تضف هذه المرحلة مكتبات أو ترحيلًا لقاعدة البيانات.

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm build
pnpm verify:build
pnpm dev
```

افتح عنوان localhost، ثم `/#S05` لليوم أو `/#S14` لصفحة «تقدمي». لا تفتح ملف index.html عبر file. البدء من سجل جديد يعرض حالات فارغة مقصودة ولا يولد نشاطًا تجريبيًا.

لإعادة التحقق وجمع سجلاته:

```sh
python3 scripts/verify-06d1.py --node /path/to/node --browser
```

يلزم Playwright Chromium مثبت، أو Chrome مع `PW_CHANNEL=chrome`. يحتاج اختبار المتصفح صلاحية تشغيل localhost. فشل المطابقة في `fsrs-selected` وحالة `release-gates` المحجوبة دليل مانع وليسا اختبارين ناجحين. يستخدم فحص البوابات معرف 05-C لأنه سياسة الاعتماد القائمة ولم يُغير في هذه المرحلة.

## حدود التسليم

- لم يتغير FSRS أو معاملاته أو النص القرآني أو المصادر والحقوق وآلية الاعتماد.
- لم يتغير main.tsx؛ سجل المنتج لا يحتوي تعلمًا مصطنعًا. جسر التعلم الموجب في الاختبارات الصناعية فقط.
- لا حاجة لإدخال نسب أو بيانات متكررة. اللوحة تعيد قراءة الأحداث بعد الحفظ وعند العودة وتغير اليوم في الرياض.
- لا نشر أو اعتماد بشري أو اختبار هاتف أصلي. راجع حدود الأدلة في التقرير.
- مجلدات docs/05a و05b و05c وتقارير README السابقة تاريخية. manifest الحالي هو delivery-manifest-06d1.json؛ لا تخلط أعداد الاختبارات السابقة مع نتائج هذه المرحلة.
